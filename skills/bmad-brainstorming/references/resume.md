# Resuming a Session

Read the chosen session's `brainstorm-intent.md` and conversation context **in full**. The intent doc restores topic, goal, and stance: reload that mode's frame (`mode-facilitator.md` / `mode-partner.md` / `mode-autonomous.md`) and hold it again. Rebuild the running tally from the conversation and the doc. Also peek at the run's board mirror (`blackboard.py read --key brainstorm.<topic-slug>` plus its `.parked`/`.branches` list) — post-compaction threads parked there refill gaps the intent doc summarized away.

Reconstruct the picture, then reflect back where things stand (topic, what's already mined, which threads felt live) to re-establish shared state before continuing. Then continue per the mode's frame (extending the same session log) — or, if they're ready to land it, go to Wrap-Up (`references/finalize.md`).
