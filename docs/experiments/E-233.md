## Experiment: E-233 — Every skeleton directory survives a fresh clone

- **Date:** 2026-11-23
- **Status:** completed
- **Record Kind:** contract
- **Theory:** skeleton.py creates twelve project directories, but three of them (docs/design/prds, docs/design/ux-designs, docs/design/architecture) are empty. Git cannot track an empty directory, so a fresh clone loses them and skeleton.py --status reports an incomplete skeleton even though init ran. The installer must leave a tracked placeholder in any directory it creates empty; otherwise the contract is true only in the working tree where install just ran.
- **Hypothesis:** H-233: "skeleton_trackability_accuracy == 1.0"
- **Measurement Metrics:** skeleton_trackability_accuracy == 1.0
- **Experiment Design:** Inputs: the twelve DIRECTORY entries in hooks/scripts/skeleton.py, the plugin tree, and a temp project installed by skeleton.py. Procedure: bench_skeleton_trackability probes each directory in both contexts and requires at least one file inside it, so git add can carry the directory. The installer writes an empty .gitkeep into every directory that would otherwise be empty, after templates are copied. Control: --broken removes the placeholders, leaving four empty directories in a fresh install (docs/quality plus the three design directories) and the bench at 8/12.
- **Code Scope:** hooks/scripts/skeleton.py, scripts/bench/bench_skeleton_trackability.py, docs/design/prds/.gitkeep, docs/design/ux-designs/.gitkeep, docs/design/architecture/.gitkeep, docs/experiments/E-233.md, docs/experiments/E-233/raw/
