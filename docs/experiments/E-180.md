## Experiment: E-180 — The dialect signatures are program diagnostics, not phrases in printed files

- **Date:** 2026-11-17
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-179 made command_not_found a shell diagnostic; the two remaining phrase-shaped classes were left behind. hooks/engine/modules/audit.py documents both of them in its own failure table, so reading that table is classified as a failure: sed -n 104,112p of the module reports bsd_sed and tells the agent to use sed -i.bak, and sed -n 120,135p reports powershell_dialect and tells it to switch to the Bash tool (both reproduced 2026-11-17). A printed file, a doc line, or a program echoing an error string is not that error; each class is only correct when the output has the shape the program prints — sed prefixes its own diagnostics with sed:, PowerShell quotes the term it could not resolve and names the error id, cmd.exe quotes the command it could not find.
- **Hypothesis:** H-180: "dialect_signature_accuracy == 1.0"
- **Measurement Metrics:** dialect_signature_accuracy == 1.0
- **Experiment Design:** Inputs: the shipped engine module hooks/engine/modules/audit.py and the pre-E-177 tree at git 205fa6d. Procedure: scripts/bench/bench_audit_dialect_shapes.py runs twelve probes in their own process against the tree under test: four PowerShell shapes that must classify (the term-not-recognized sentence, the FullyQualifiedErrorId line, cmd.exe quoted form, the token-not-a-separator sentence), two BSD sed diagnostics that must classify (flat and on stderr), one class-routing probe (a glob abort still routes to glob_nomatch), and five prose payloads that must stay silent (the failure table comment that names invalid command code, the regex table that names CommandNotFoundException, the whole module source, a doc sentence naming both phrases, and an end-to-end audit() call over the table comment that must write no row and warn nothing). Control: --broken runs the same probes against 205fa6d, whose bare phrase regexes fire on every prose payload. Reproducibility: stdlib only, offline, deterministic (git archive prefix tree; no network, no clock dependence).
