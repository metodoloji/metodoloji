## Experiment: E-203 — The install digest finds every shadow copy and counts what it names

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** The duplicate-install hunt carried two silent caps. install_digest walked each cache base with [:5], so a home with eight cache copies reported five and the other three were never discovered — not withheld-but-counted, simply invisible. Both surfaces that print the shadows then joined [:3] of that list, so five looked like three. That is the exact failure this section exists to prevent: its docstring records a real session that burned turns catting SKILL.md from two installs and running find / -name metodoloji to decide which was canonical. An agent told there are three shadow copies has no reason to suspect a fourth, and a digest that lists three of eight is a claim about the whole home. The scan now lists every entry, the digest carries shadow_count so the count comes from the scan rather than from the display bound, and both the next step and the render name three through the repo's counted_list convention — the same join E-196/197 put behind every other bounded list.
- **Hypothesis:** H-203: "shadow_install_accuracy == 1.0"
- **Measurement Metrics:** shadow_install_accuracy == 1.0
- **Experiment Design:** Inputs: a scratch HOME per probe (placeholder home for the claim, git archive of PREFIX_REV for the control) holding .claude/plugins/cache/yunusgungor/metodoloji with the probe's version directories, read through the shipped install_digest, orient.build next_steps and the shipped orient.py text render, with HOME set per probe because Path.home() is read at call time. Seven probes: eight cache copies are all found and all counted as shadows; the digest's shadow_count matches the list and both surfaces carry the same (+5 more shadow installs); the next step counts its remainder; the render counts its remainder; the step names exactly the first three and no later one; a single copy carries no marker; and a cache entry that resolves to the canonical root is not a shadow. Procedure: each probe plants its home, invokes the shipped functions (the render as a subprocess so it sees the same HOME), and reads the text they produce. Control: --broken repeats this against E-202's commit f7cf51d, whose scan stops at five per base and whose two surfaces join three silently — 2/7, the passes being the behaviours the change did not touch (a single copy unmarked, a canonical copy not flagged). Reproducibility: stdlib plus git, offline, deterministic.
