## Experiment: E-078 — Version compatibility flags do not accept substring matches

- **Date:** 28.10.2026
- **Status:** completed
- **Theory:** The external-context finder reports `version_match` by checking whether the supplied version text occurs anywhere inside the analyzed version/ref. A request for `1.2` therefore matches `11.2.0`, even though the analyzed context may target a different major version. Workflows use this field to decide whether to revalidate version-sensitive evidence, so a false positive weakens that decision.
- **Hypothesis:** H-078: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the current consistency bench and its `--broken` seeded-defect control. Add exact-ref comparison coverage to finder tests and the consistency contract probe, including the false-positive pair `1.2` versus `11.2.0` and an equal ref with optional leading `v`. The bench control will mutate the matcher back to substring behavior and must catch that behavior regression. Reproducibility is local and offline.
- **Sample Size n:** measured from the bench output
- **Code Scope:** scripts/find-external-contexts.py, scripts/tests/test_find_external_contexts.py, scripts/bench/bench_consistency.py, scripts/tests/test_selfcheck_scripts.py, docs/experiments/E-078.md
