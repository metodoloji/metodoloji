## Experiment: E-107 — A guard that cannot be made red is not a guard: the change-radar checks must detect their own drift

- **Date:** 03.11.2026
- **Status:** completed
- **Theory:** E-043 turned the change radar from prose into a contract: `EXPECTED_SUBSCRIPTIONS` in `scripts/check-handoff.py` declares the intended (pattern, channel) set, the lint compares the skills to it, and `bench_consistency._check_change_radar_contract_matches` derives the shipped radar from the tree and compares it to both runbooks. The code review of 043e7ba found that the contract guards only one diagonal of the triangle. The lint comparing the declared table to the skills prints `[WARNING]` but never increments `problems` (`check-handoff.py:703-726`, `:736-741`), so a coordinated skills+runbooks edit leaves the table stale with a green CI; the bench never loads the table at all. The bench's own failure paths have no falsifier: `test_selfcheck_scripts.py:1032` asserts only `is None` on a tree where the answer is already `None`, so an implementation reduced to comparing skill names would still pass — the exact regression E-043 fixed. An unreadable `SKILL.md` is silently dropped from the measured set (`bench_consistency.py:3276-3279`), so a measurement failure is reported as a pass. And `_SUBSCRIBE_RE` (both copies) has no left boundary, misses `--channel=X`, and captures a trailing backtick, so valid CLI spellings are mis-parsed. The theory under test: a guard is only a guard if its own drift makes it red — every one of those paths must be detectable by a trial that a broken implementation fails.
- **Hypothesis:** H-107: "guard_detection_accuracy >= 0.90"
- **Measurement Metrics:** guard_detection_accuracy >= 0.90
- **Experiment Design:** Measure `scripts/bench/bench_guard_drift.py`: 11 samples — 10 drift trials plus one clean control — over synthetic project trees (built in a temporary directory, `bench_consistency.ROOT` swapped for the duration). A trial passes when the shipped guard reports a problem for the injected drift and stays silent for the clean tree. Groups: (1) four pre-existing drifts that must stay caught — wrong documented pattern, documented skill omitted, phantom documented skill, undocumented shipped pair; (2) two declared-table drifts that the pre-fix surface cannot see — declared table disagrees with a consistent tree, declared table names a skill that ships nothing; (3) one measurement failure — a `skills/<name>/SKILL.md` that cannot be read (a directory) must be reported, not skipped; (4) three CLI spellings — `unsubscribe --watcher …` must not count as a subscription, `--channel=stop` must count, and a trailing backtick/code-span delimiter must not become part of the channel; (5) one clean tree that must stay silent. The `--broken` control is the pre-fix surface (old regex, no table cross-check, silent unreadable skip) kept in the harness; the gate runs it and it must score below 0.90. Deterministic, offline, stdlib only; one JSON object per trial with a boolean `ok`.
- **Sample Size n:** 11 samples (10 drift trials + 1 clean control)
- **Code Scope:** scripts/check-handoff.py, scripts/bench/bench_consistency.py, scripts/bench/bench_guard_drift.py, scripts/tests/test_check_handoff.py, scripts/tests/test_selfcheck_scripts.py, docs/experiments/E-107.md, docs/experiments/E-107/raw/

No prior record measured guard falsifiability itself.
