## Experiment: E-182 — A trail row must re-classify to the class it recorded

- **Date:** 2026-11-17
- **Status:** completed
- **Record Kind:** contract
- **Theory:** The audit trail exists so a later session can count failures per class: the module comment says so and the records Next Steps ask for that baseline. But audit() writes output_summary as str(tool_output), a Python repr with escaped newlines, truncated at 500 characters. Every signature in the table is anchored to a line start, and a repr has none, so a stored row cannot reproduce its own class: a multiline zsh nomatch recorded as glob_nomatch replays to None, and a 2000-character output whose diagnostic sits at the tail replays to None while the write-time class was bsd_sed. Reproduced 2026-11-17 against ba05e5a. The trail therefore carries a class that nothing in it can justify, and the stored text is unreadable to a human as well.
- **Hypothesis:** H-182: "trail_replay_accuracy == 1.0"
- **Measurement Metrics:** trail_replay_accuracy == 1.0
- **Experiment Design:** Inputs: the shipped module hooks/engine/modules/audit.py and the pre-E-182 tree at git ba05e5a. Procedure: scripts/bench/bench_audit_trail_replay.py drives audit() in its own process over twelve terminal/editor payloads in a temporary project root, reads back the log line it wrote, re-classifies the stored output_summary with command_failure, and requires the replayed class to equal the class written in the row: multiline glob/command-not-found/backslash diagnostics, a stderr-only diagnostic, a nested envelope, a long output with the diagnostic at the head, a long output with it at the tail, two silent rows (long and multiline), a row with no output at all, and a file_editor row whose body must stay bounded. Control: --broken runs the same probes against ba05e5a, whose repr-and-500 storage loses every multiline and tail diagnostic. Reproducibility: stdlib only, offline, deterministic (temporary root per probe, no clock or network dependence in the compared values).
