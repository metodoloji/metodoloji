## Experiment: E-022 — A new experiment must carry what the prior ones proved

- **Date:** 10.10.2026
- **Status:** completed
- **Theory:** The E corpus is the methodology's memory, but nothing asks a new
  record what the earlier ones already proved. 21 records ship under
  `docs/experiments/` and **not one** carries a machine-readable link to
  another: a scan of the tree finds zero records with a lineage/related field,
  the only carry-forward is prose inside some `Theory` fields (E-018/E-020/E-021
  name each other's class in passing), plus the retrospective→research
  blackboard handshake, which is advisory and only fires after a retro. The gate
  validates `Theory`/`Hypothesis`/`Measurement Metrics`/`Experiment Design`/
  `Code Scope` and then measures — a draft that never opened a prior record
  passes exactly as one that read all 21. That makes the corpus write-once: the
  same lesson gets re-learned, a rejected hypothesis can be silently re-run
  under a fresh id, and an experiment's contribution (the scope it opened, the
  finding it closed) is never consulted again. The root cause is the class
  E-018/E-019/E-020/E-021 named — a guarantee exists only where its wiring is —
  with the wiring absent here entirely: the record has no field, the gate has no
  check, the audit has no section. The fix is the same shape those records used:
  give the record a `Lineage` field and make the GATE refuse a draft that does
  not declare it (`none` for a genuinely new line of inquiry, otherwise the
  prior E-ids it carries), refuse a dangling or self-citing claim, and refuse
  silence about a REJECTED record whose `Code Scope` this draft re-treads (P9: a
  rejection is a lesson the next record carries, not a hole to re-run). The E
  template, the manifesto's required-field list and the skill's Theory stage
  then teach the field, and a bench check pins the enforcement and re-resolves
  every declared ref in the corpus.
- **Hypothesis:** H-022: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit.
  Procedure — run `python scripts/bench/bench_consistency.py`, which evaluates
  independent doc/code-consistency claims and prints
  `consistency_accuracy=(x/y)`; one new check pins the E-022 claim: it drives
  the gate (`run_experiment.py --record <temp draft> --run ...`) on a minimal
  valid draft that carries no `Lineage` line and demands exit 2 with the field
  named, asserts both E templates ship the field, and re-resolves every
  `Lineage` ref declared under `docs/experiments/` so a dangling claim cannot
  sit in the corpus — plus the regression tests by name. Control — the bench's
  own "pytest suite green (falsifier)" check pins that the code under test still
  passes the full suite, which now includes the `lineage_issue` unit tests in
  `test_run_experiment.py` and the E-022 pin in `test_selfcheck_scripts.py`. The
  probe is falsifiable by construction: removing the `lineage_issue` call from
  the gate's `main()` turns the new bench check red (the draft is then measured
  instead of refused), and stripping the `Lineage` line from either template
  fails the template assertion. Reproducibility — stdlib only, no network,
  deterministic: the check reads the tree and drives the gate as they are, and a
  fixed tree yields a fixed x/y; the measurement reports the tree as it is,
  independent of this record (E-001).

  no corpus and rule (3) cannot fire — accepted, because a record outside
  `docs/experiments/` is already outside the chain (`create-methodology-record.py`

  only; the free-text note after them (what the record inherits) is for the

  why the refs themselves are. The rejected-overlap rule (3) is vacuous on this
  tree (all 21 records are `completed`; none is REJECTED), so its bench coverage
  is the unit test, not a live record — the same "passes today, closes the hole
  tomorrow" shape E-020/E-021 used. Rule (3) compares scope by shared path token
  (exact pattern or first two path segments), not by glob subsumption, so a
  renamed-but-overlapping scope is not caught; widening it to subsumption is the
  natural follow-up once a REJECTED record exists to test against.
