## Experiment: E-209 — The stale-approval denial reports the whole blast radius

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Under [hooks] freshness = deny, find_approved refuses to open code through a STALE record and prints why: "but the code has moved past it: <reason> (a.py, b.py, c.py changed after approval, witness <sha12>)". The path enumeration came from fresh["changed"][:3] — three paths, no marker, no count. The STALE detail carries every scoped path that moved, up to [freshness] max_digest_files; measured live on this tree 2026-11-22, 82 records were STALE with more than three changed paths (E-148: 145, E-038: 271, E-150: 94, E-050: 89). The denial is what a reader sizes the remedy on — re-measure in a new record, or amend the plan to declare the files — so three paths presented as the enumeration understate the blast radius and invite a remedy too small for it. The notice now prints the one shared bounded-list form: three paths, then "… (+N more paths)". A verdict with no paths (a supersede) keeps the existing "code state" wording and gains no marker.
- **Hypothesis:** H-209: "stale_notice_blast_radius_accuracy == 1.0"
- **Measurement Metrics:** stale_notice_blast_radius_accuracy == 1.0
- **Experiment Design:** Inputs: the shipped scope_gate.find_approved denial, driven through a throwaway project with a stub record, a stub gate that scope-matches, and a STALE freshness detail of a given length. Six probes: five changed paths render three then "(+2 more paths)"; a twenty-path list names exactly three and counts seventeen; a two-path list prints verbatim with no marker; a zero-path (supersede) verdict keeps "code state" and no marker; a 145-path list counts 142 withheld; and the witness anchor marks the reason. Procedure: each probe runs in its own subprocess against the tree under test and reads the rendered string. Control: --broken repeats this against E-205 commit 26b83f8, whose changed[:3] names three paths and no remainder — 2/6, the passes being the short list and the empty detail the slice never touched. Reproducibility: stdlib only, no git needed, deterministic.
