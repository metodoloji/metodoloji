## Experiment: E-088 — Discovery never presents an unreviewed draft as registered context

- **Date:** 29.10.2026
- **Status:** completed
- **Theory:** The registry has two halves that disagree about the same file. The authoring half (`external-context.py check`) fails an entry whose `Status` is not `reviewed` with 13 findings and the line "entry is still a draft", and `finalize` is what registers an entry in the README index. The consuming half (`find-external-contexts.py`) reads every `*/context.md` in the folder and returns an explicitly draft scaffold with the same score as a finished entry — no `status` field, no warning — while the methodology instructs workflows to "read every returned `path` that is relevant" and to record its analyzed ref. A workflow can therefore load a half-finished scaffold as registered evidence and never learn that it was unreviewed. Reported results are called "registered context" in the tool's own message text, which a draft is not.
- **Hypothesis:** H-088: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the current consistency bench and its `--broken` seeded-defect control. Extend `find_contexts` to parse each entry's `Status`, carry a `status` value on every returned result, exclude entries explicitly marked `Status: draft` from `results` into a new `drafts` list with a warning per path, and keep entries without a `Status` field in `results` as `status: unknown` (the shape every existing discovery test pins). Add unit tests: a draft is never a result but is reported as a draft with a warning, a reviewed entry is returned with `status: reviewed`, and a `Status`-less entry still returns as `status: unknown`. Seed removal of the draft filter in broken mode. Update the consuming surfaces that tell workflows what a result is. Reproducibility is local and offline.
- **Sample Size n:** measured from the bench output
- **Code Scope:** scripts/find-external-contexts.py, scripts/tests/test_find_external_contexts.py, scripts/bench/bench_consistency.py, scripts/tests/test_selfcheck_scripts.py, docs/bmad/research-methodology.md, commands/add.md, docs/experiments/E-088.md
