## Experiment: E-212 — The orient panel names each MCP config once and counts the rest

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** The orient panel's MCP sources line took the enabled servers, sliced them to three before printing, and printed each server's config path — with no dedupe and no count. Live on 2026-11-22, five enabled servers in one project .mcp.json rendered the same path three times: sources: project:./.mcp.json, project:./.mcp.json, project:./.mcp.json. So a five-server session showed one source, repeated, and two servers disappeared without a word; with servers spread over four or more configs the bound hid whole config files instead. The steering next-step one block up carried the matching shape: a bare (+1) with no noun. The sources line now dedupes by config source, keeps the first-seen order and goes through the panel's own counted join (E-203); the steering step names its unit, singular and plural.
