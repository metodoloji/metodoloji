## Experiment: E-187 — Elide a run key at a boundary, never inside its gate token

- **Date:** 2026-11-21
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Measured live on this tree, 2026-11-20: the session start context printed 'Chain progress — E: E-186: APPROVED: measured=1.0 == threshold=1.0 (GATE-OK-E-18'. The run key's value ends in its gate token, and three shipped surfaces bound that value by slicing — compact_context and the doctor's methodology block at 80 characters, the session edge again at 60. On this very project the two bounds composed, so the most durable surface a session sees handed out a stub of a gate token: unverifiable, and indistinguishable from a corrupted token. The bound itself is right (the edge carries six stages); where it lands was not. This is the F-03 lesson one layer down: a surface that repeats a claim must not mangle the evidence that makes the claim checkable.
- **Hypothesis:** H-187: "chain_brief_accuracy == 1.0"
- **Measurement Metrics:** chain_brief_accuracy == 1.0
- **Experiment Design:** Inputs: run keys written through the shipped board API into throwaway projects, then read through the three shipped surfaces — blackboard.compact_context, blackboard_diagnostics.doctor and audit.session_start (the real hook entry point is driven as a subprocess for the session probe). Procedure: scripts/bench/bench_chain_brief.py runs ten probes — short value verbatim, boundary not mid-word, gate token never fragmented, decision and claim survive, an unclosed bracket dropped whole, exactly one elision marker, doctor elides, session edge elides, session stage bounded, and all three bounds hold. Control: --broken runs the same ten probes against the pre-change tree at git c302171, whose raw [:80]/[:60] slices cut the token. Reproducibility: stdlib only, offline, deterministic; each probe gets a fresh temp project and its own process.
