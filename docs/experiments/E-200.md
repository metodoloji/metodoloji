## Experiment: E-200 — The MCP steering line counts the servers it withheld

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** mcp_steering_line was written as 'the same contract as format_sprint_line' and copied that line's defect: it joined four server names and then a bare ', …', so seven enabled servers read as four with nothing saying three were missing, and the finished string was still sliced by line[:200] — which can cut a name in half and eat the only marker admitting the shortening. Observed live: a board with seven enabled servers emitted 'mcp: 7 active server(s) — claude.ai Atlassian Jira Cloud, claude.ai Figma Context Server, claude.ai Google Drive, claude.ai Linear, …', and with longer names the injected sentence ended mid-name ('… claude.ai Playwright Bro'). The line reaches every session opener through the same inject as the sprint line, so an uncounted bound there is the same false claim about the whole set E-198 removed one surface away. The fix routes the line through the part-bounded join: every enabled server is named whole or counted in '… (+N more)', the 200-character bound is enforced while building (never by slicing), and a single name wider than the line is elided with its prefix kept.
- **Hypothesis:** H-200: "mcp_line_bound_accuracy == 1.0"
- **Measurement Metrics:** mcp_line_bound_accuracy == 1.0
- **Experiment Design:** Inputs: a scratch project root per probe (the working copy for the claim, git archive of PREFIX_REV for the control) holding an .mcp.json with the probe's servers, read through the shipped state.mcp_inventory and state.mcp_steering_line (or the shipped audit.session_start for the inject probe). Eight probes: seven short names with a counted remainder, six long names with the count matching the names actually withheld, every shown fragment being a whole configured name, the 200-character bound on the long fixture, one 400-character name elided with its prefix kept and the elision marked, disabled servers neither named nor counted, the session-start inject carrying the counted line, and no trailing slice left in the function. Procedure: each probe writes its .mcp.json, calls the shipped function, and reads the line it emits. Control: --broken repeats this against E-199's commit bad08ce, whose function joins names[:4] plus a bare ', …' and slices the result at 200 — 2/8, the passes being the behaviours the change did not touch (the length bound still holding, and disabled servers still excluded). Reproducibility: stdlib plus git, offline, deterministic.
