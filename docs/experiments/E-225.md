## Experiment: E-225 — The sprint line names the unit of every withheld part

- **Date:** 2026-11-23
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-203..E-224 named the unit on every bounded list the session edge and reports print, but state._bounded_parts_line still ends a wide sprint line with a bare '; … (+N more)'. That line is injected at session start, printed by stop and by orient, and its parts mix epic warnings with status groups — so a reader cannot tell whether the withheld entries are stories, warnings or groups, and the one remaining bare marker is on the surface an agent reads first. Naming the unit ('entry'/'entries') closes the campaign and keeps the singular/plural rule explicit.
- **Hypothesis:** H-225: "sprint_parts_count_accuracy == 1.0"
- **Measurement Metrics:** sprint_parts_count_accuracy == 1.0
- **Experiment Design:** Inputs: a scratch project root with a generated sprint-status.yaml. The shipped state.format_sprint_line renders it; audit.session_start renders the same line for the live-inject probe. Seven probes: a line that fits prints with no marker; a singular remainder reads '+1 more entry'; a plural remainder reads '+3 more entries'; a lone oversized part elided at the line's edge still ends '+1 more entry'; no marker matches the bare regex '\(\+\d+ more\)'; the 200-character bound holds on a wide board; and the session-start inject carries the unit. Control: --broken repeats against 2497e68, the tree before this change, where the marker is bare (5/7 fail).
