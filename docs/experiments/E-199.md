## Experiment: E-199 — A shortened alert on the session edge says it was shortened

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Found live on this tree on 2026-11-22. A commit that missed files outside an approved scope posts a scope-debt alert, and the very next session-start injected 'SCOPE DEBT — commit missed 3 files outside any approved scope: docs/development/native/segments/07-runtime/segment-note-runtime-tail.md, hooks/engine/modules/blackboard_diag.' The session edge sliced the alert text at 160 characters: the cut landed inside a filename, and no marker accompanied it, so the sentence read as complete while naming a file that does not exist — the reader has no way to tell a shortened alert from a whole one, and no reason to go read the board. The routed-alert branch beside it carried the same raw slice. E-192 fixed this exact slice on the stop edge and E-193 on the guard quotes, but the session edge — the surface every session opens with — kept it. The fix routes both branches through the shared cutter (utils.brief_text): a shortened alert is a prefix of the original, cut on a token boundary, with an unclosed bracket group dropped whole and the elision marked by '…'; the board keeps the full text, so nothing is lost, only deferred.
- **Hypothesis:** H-199: "alert_elision_accuracy == 1.0"
- **Measurement Metrics:** alert_elision_accuracy == 1.0
- **Experiment Design:** Inputs: a scratch board per probe (the working copy for the claim, git archive of PREFIX_REV for the control) holding a scope-channel alert whose text names two long repo paths, a session-channel one, or the specific fixture a probe needs (three alerts on a channel, a short text, an unclosed parenthesis). Eight probes: the scope alert's cut is marked and no corrupted filename reaches the inject; that cut is on a token boundary (the injected text is a prefix of the alert and the next original character is a boundary); the routed branch bounds the same way; a channel with three alerts still counts the withheld ones ('(+2 older)' / '(+2 more routed)'); a short alert is quoted verbatim with no marker; an unclosed bracket group is dropped whole rather than left open; the board still holds the full text; and audit.py carries no raw alert slice. Procedure: each probe posts its alerts, calls the shipped audit.session_start, and reads the injected sentence and the board. Control: --broken repeats this against E-198's commit bad08ce, whose session edge slices both branches at 160 characters — 3/8, the passes being the behaviours the change did not touch (the remainder counts, a short alert quoted whole, the full text on the board). Reproducibility: stdlib plus git, offline, deterministic.
