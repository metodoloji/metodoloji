## Experiment: E-152 — Every retired doc is gone from every live surface, and the set is closed

- **Date:** 2026-11-14
- **Record Kind:** contract
- **Status:** completed
- **Theory:** E-151 retired docs/methodology.md and pinned that one path with a probe. It left the general invariant open in its own Known Gap 5: "every {metodoloji-root}/... path in a live surface resolves" was not measured, so a future retirement could leave another dead path with nothing to catch it. Meanwhile the concurrent removals (2064fa9, d12c269, 5398dbd) had already deleted nine more docs — GUIDE.md, KILAVUZ.md, AGENT-GUIDE.md, AGENT-GUIDE-TR.md, CONTRIBUTING.md, docs/CLAUDE.md, docs/architecture.md, docs/VERSION-HISTORY.md, docs/STALE-CONTEXT-REMEDIATION.md, docs/runtime-security-coverage.md — and emptied README/LICENSE/SECURITY. The checkers, benches and tests still read those paths: bench_consistency alone carried 48 failing probes, and the suite carried 18 failures, every one a FileNotFoundError on a file that no longer ships. That is not noise to be silenced file by file; it is one rule measured 48 times: a live surface that names a retired doc is a dead instruction. This change closes the set: the retired list becomes data, one probe scans every live surface for any member of it, and every checker/bench/test that read a retired doc either points at the live owner or drops the half of its claim whose subject no longer ships.
- **Hypothesis:** H-152: "chain_handoff_accuracy == 1.0"
- **Measurement Metrics:** chain_handoff_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit plus the pre-change tree extracted from PREFIX_REV with git archive (the control arm). Procedure: scripts/bench/bench_chain_handoff.py runs seventeen probes. Sixteen are E-150/E-151's, unchanged in substance but with _LIVE_GLOBS retargeted at the surfaces that actually ship (README, docs/*.md, commands, templates, SKILL.md, customize.toml, hook scripts) — the four retired runbooks were removed from that glob, which is what had made two E-151 probes pass only by reading files that no longer exist. Probe 17 is new: no live surface names a retired doc. It matches two pointer forms — a {metodoloji-root} path into a deleted doc, and a markdown link to a root runbook — so a bare word like "GUIDE.md" in the target project's own vocabulary is not a false positive. Control: --broken runs the same seventeen probes against the pre-change tree and must score below the threshold. Falsified both ways: appending a markdown link to GUIDE.md in a SKILL.md drops the score to 16/17, and appending a {metodoloji-root}/docs/CLAUDE.md pointer in docs/OPENCODE.md does the same; the tree was restored after each. Reproducibility: stdlib only, deterministic, no network.
