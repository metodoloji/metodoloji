## Experiment: E-193 — Denial details quote the offending line on a boundary

- **Date:** 21.11.2026
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Found live on this tree, 2026-11-21, by asking guard to validate a story whose Technical Tasks section carried a long path: 'Task without AC reference: - [ ] wire the release path docs/planning/implementation-rea...'. The quote was task_text[:60] plus three dots, so the denial cut the path mid-word and dropped whatever followed — the AC id, or a gate token, that the reader needs to act on. utils.dod_issues carried the identical cut for its two DoD messages, and guard prints both families in the same denial, so a reader got one marked-looking, mid-word quote after another. The fixed '...' also marked text that was not shortened at all: a 44-char task printed with a trailing ellipsis, making a complete quote look truncated. The engine owns the right cutter (utils.brief_text), and these messages were simply not using it.
- **Hypothesis:** H-193: "denial_quote_bound_accuracy == 1.0"
- **Measurement Metrics:** denial_quote_bound_accuracy == 1.0
- **Experiment Design:** Inputs: in-memory story documents handed to the shipped guard validator and DoD section text handed to the shipped dod_issues() — a long task line whose path and gate token start before the 60-char cut, a short task that fits, and a DoD item whose cut would fall mid-path or bypass a token. Procedure: scripts/bench/bench_denial_quote_bound.py runs ten probes through the shipped messages — the quote is not cut mid-word, ends with a marked elision, is a true prefix cut on a boundary character, never carries half a token, a quote that fits prints verbatim with no marker at all, the two DoD messages are bounded the same way, the DoD token is whole or absent, every quote stays inside bound plus marker, the quote equals utils.brief_text(text, 60), and the denial still denies. Control: --broken runs the same probes against the pre-change tree at git 0953f6b (which predates E-192 as well; neither change is in that tree), whose quotes are text[:60] + '...'. Reproducibility: stdlib plus git only, offline, deterministic; each probe runs in its own process.
