## Experiment: E-161 — A shipped surface carries content, and no check is vacuously satisfiable

- **Date:** 2026-11-14
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Measured 2026-11-14 on this tree at e18a677: commit 2064fa9 deleted README.md, LICENSE and SECURITY.md, and a later commit re-created all three as ZERO-BYTE files. Four removal benches went red — each asserts that the reader-facing surface declares the surviving skill count, which an empty file cannot — and nobody saw them, because no workflow runs a bench. The deeper defect is how the red was silenced: E-152's commit set bench_consistency's four _AUDIT_* tuples to empty tuples to match the emptied README, so the audit-inventory probes iterated over nothing and passed vacuously. The one instrument that reads README for a living was told to read no documents. That is E-159's dead reference one level up — not a surface naming nothing, but a RULE measuring nothing, which is strictly worse because it reports success.
- **Hypothesis:** H-161: "shipped_surface_accuracy == 1.0"
- **Measurement Metrics:** shipped_surface_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit plus the pre-repair tree at PREFIX_REV (e18a677). Procedure: scripts/bench/bench_shipped_surfaces.py enumerates the population by AST and a fixed required list, and asserts four properties: (1) every reader-facing file named in REQUIRED_NONEMPTY is non-empty; (2) every manifest that declares a license ships a LICENSE saying the same thing; (3) every module-level _AUDIT_* tuple in bench_consistency names at least one document and every document it names ships — a check with an empty population is refused, because it reports a pass it never measured; (4) the same probes run against the live tree so this record's own fix is pinned. The repair restores the three emptied files, re-arms the four emptied _AUDIT_* tuples to name README.md, and adds the audit-count sentence the re-armed probe requires. Control: --broken evaluates PREFIX_REV, where all three files are empty and all four tuples are empty, and must score below the threshold. Reproducibility: stdlib + git, offline, deterministic.
