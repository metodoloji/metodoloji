## Experiment: E-208 — The session-edge advisory names the whole evidence command

- **Date:** 2026-11-22
- **Status:** completed

- **Theory:** The workflow advisory is the one sentence a resumed session reads first, and it says what the current stage completes with. _evidence_hint printed argv[:3]. For the builtin methodology-chain spec every non-terminal stage therefore rendered the same command: "command {python} {metodoloji-root}/hooks/scripts/chain-gate.py --stage (rc=0)" — a flag with no value, no slug, no project root, identical across experiment, implementation-readiness, sprint-planning, story, quality-review and production-readiness (observed live 2026-11-22). The hint exists so the agent runs the thing the kernel will check; a command elided in the middle is a different command — it cannot be run, cannot be told apart from another stage, and reads as a malformed invocation of the gate. The argv is authored by the spec, so its length is the spec author's decision, not a surface bound to hide; the hint prints it whole.
