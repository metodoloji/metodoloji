## Experiment: E-113 — Every capped plane announces what it drops: the silent subscription fold

- **Date:** 05.11.2026
- **Status:** completed
- **Theory:** The board bounds every plane it owns, and the two planes with the longest history already say so out loud when they expire an entry: `write_key` prints `bounds enforced — keys <used>/<cap>, oldest expired` (`hooks/engine/modules/blackboard.py:717`) and `notify` prints the same for alerts (`blackboard.py:1337`). Subscriptions have the cap (`MAX_SUBSCRIPTIONS = 16`, `blackboard.py:109`) but not the announcement: the fold enforces it with a bare `board["subscriptions"].pop(0)` (`blackboard_fold.py:230-231`), so the seventeenth watch silently destroys the oldest and leaves no trace in any output. This repository is two registrations away from that state (14/16 at the digest), which is why a finding raised during the S-001 code review is worth closing now rather than after the first live watcher disappears.
- **Hypothesis:** H-113: "cap_observability_accuracy >= 0.999"
- **Measurement Metrics:** cap_observability_accuracy >= 0.999
- **Experiment Design:** Register 17 distinct watchers against a fresh temporary project root through the shipped `modules.blackboard.subscribe`, capturing stderr around the call that crosses the cap. Eleven checks then decide whether the eviction is observable and whether the plane still behaves as a plane: the cap constant matches its declared value; the overflow emits a bounds notice; the notice names the plane; the notice carries `<cap+1>/<cap>`; the plane holds exactly at the cap; the oldest watcher is the one evicted (FIFO); the newest is retained; the call still acknowledges success; re-subscribing an existing pair does not grow the plane; unsubscribing after an eviction still removes exactly one; and the shared notice emitter covers the key plane that already used it. The control is the pre-fix surface reproduced by silencing the notice emitter — the message is produced and never reaches stderr, which is exactly what the shipped fold does today. Deterministic, offline, stdlib only.
- **Sample Size n:** 11 checks
- **Census:** The eleven checks enumerate every behaviour the subscription cap owns — announcement, plane, counts, cap, FIFO eviction, retention, acknowledgement, dedupe, unsubscribe and the shared emitter — so they are the surface itself, not a sample drawn from a larger one. No sampling inference applies to the verdict; the control still has to fail the same claim.
