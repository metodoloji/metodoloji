## Experiment: E-073 — Rule 7 gets a user, and the canvas's third category gets a pin

- **Date:** 24.10.2026
- **Status:** completed
- **Theory:** The gate's own output was the evidence. E-072 — the record that
  repaired the corpus — was stamped `Falsifiability: UNVERIFIED — no control
  command declared`, and a sweep of the corpus found the same for every record
  ever written: the rule-7 mechanism (measured 2026-10-24 on a throwaway
  fixture: a passing control refuses with exit 3, a failing one approves) ships,
  works, and is exercised by nobody. A mechanism with no user and no test is a
  claim about a mechanism: the gate can separate working code from broken code
  only in principle. The repo's primary instrument, `bench_consistency.py`, had
  no broken mode at all, so its own claim (`consistency_accuracy >= 0.90`) could
  never be shown to fail — the exact shape of the rule it enforces.
  The same pass found a second, cheaper gap: `E-072`'s Known Gaps recorded that
  the runbooks' AC sub-field list was unmeasured. The story canvas accepts three
  home for a criterion (`Experiment: E-NNN` measured, `Experiment: STRUCT-NNN`
  structural, `Test: path::name` a specification a test decides) and both
  runbooks now teach all three, but nothing compared that list to the canvas —
  so the next edit could narrow it back to one category silently, exactly as it
  already had been narrowed when the third category landed.
- **Hypothesis:** H-073: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit.
  Procedure — `python scripts/bench/bench_consistency.py` evaluates the 116
  independent doc/code claims and prints `consistency_accuracy=(x/y)`. The new
  `--broken` mode copies the tree to a temp directory, seeds one defect per rule
  family (16 defects across 12 files: stale public counts, a stale suite size, a
  ghost command, a `# map:` missing a section, a stale hook-comment count, an
  unhooked declaration audit, a drifted gate-mode block, a dropped `Test:`
  bullet, a CI step that would commit), and runs the same check list on the copy
  — the live tree is never written, and the pytest subprocess is excluded because
  the control measures the rules, not the copy's suite. Control —
  `python scripts/bench/bench_consistency.py --broken`, declared in this record
  and run by the gate itself: it measured 0.85 (98/115) before this record was
  measured, which does not clear the claim, so the instrument is falsifiable.
  A mutation whose anchor rots stops being injectable, and that is a hard
  BROKEN-SETUP failure (exit 2) rather than one fewer defect — the E-048
  lesson applied to the control. Rule 7's own two outcomes are pinned
  end-to-end in `skills/bmad-research-experiment/scripts/tests/
  test_run_experiment.py` (passing control → exit 3, no Decision written;
  failing control → APPROVED with the proof recorded). The AC pin is a bench
  check: the canonical story template owns the category set and both runbooks'
  §"Acceptance Criteria" section must teach the same set plus the STRUCT
  variant; a unit test drops the `Test:` bullet from GUIDE and requires the
  check to name the file. Reproducibility — stdlib only, no network,
  deterministic: a fixed tree and fixed seeds yield a fixed x/y, independent of
  this record (E-001).
- **Sample Size n:** 116 (informational — the gate parses the denominator from
  the bench output; the count grows from 115 with the AC-category check)
- **Code Scope:** scripts/bench/bench_consistency.py, scripts/tests/test_selfcheck_scripts.py, skills/bmad-research-experiment/scripts/tests/test_run_experiment.py, docs/experiments/E-072.md
