## Experiment: E-093 — External-context writes cannot escape through an ancestor link

- **Date:** 31.10.2026
- **Status:** completed
- **Theory:** E-092 made every *existing* entry path prove that it resolves inside the registry before any read or write, but both commands that create a path were left unproven. `prepare` builds `registry/<slug>/context.md` and calls `atomic_write_text`, whose `mkdir(parents=True)` follows an existing folder link: a pre-created symlink or junction named with the chosen slug (with no `context.md` yet, so `_entries` skips it) receives the scaffold outside the project. `discard` builds `registry/.archive/<stamp>-<slug>` and moves the entry there; `.archive` is a dot-directory the audit never visits, so a linked `.archive` moves the reviewed entry and writes `ARCHIVED.md` outside the project. Two measured probes reproduced both escapes on this host (a Windows junction; `outside/context.md` and `outside2/<stamp>-ok/{context.md,ARCHIVED.md}` appeared). The theory under test is that the boundary rule must cover the nearest existing ancestor of a path that is about to be created, not only paths that already exist, and that one shared guard can serve both writers.
- **Hypothesis:** H-093: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the focused write-boundary bench `scripts/bench/bench_external_context_boundary.py` (six cases: a refused outside ancestor, `prepare` through a linked entry folder, `discard` through a linked `.archive`, and the three paired safe-write controls — a missing leaf inside the registry, a normal `prepare`, a normal `discard`) and its `--broken` control, which removes the guard in memory: the three escape cases must fail while the three safe cases still pass. Add a shared `require_inside_target(path, parent, label)` to `external_context_common.py` that walks to the nearest existing ancestor (or symlink), resolves it, and refuses the target when that ancestor escapes the registry; a missing path whose existing ancestors are all inside is returned unchanged. Call it from `prepare` before `mkdir`/write, and from `discard` for both `.archive` and the chosen archive target before `shutil.move`. Pin the pure path rule (outside ancestor refused, safe missing leaf accepted) in the consistency bench, and seed removal of the guard in broken mode so the contract is falsifiable. Pin the two CLI wirings with unit tests that create a directory symlink, or a Windows junction when symlinks need a privilege, and assert the outside directory stays empty while the entry is untouched. Reproducibility is local, deterministic and offline.
