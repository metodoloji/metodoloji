## Experiment: E-150 — The methodology chain is driven by the kernel, not by prose

- **Date:** 2026-11-13
- **Status:** completed
- **Record Kind:** contract
- **Theory:** The methodology chain was specified in prose: `docs/bmad/` held the order, the record formats and a status vocabulary per record kind, each restated from the code that actually decided it. The workflow kernel shipped with the plugin and no run had ever been created for it — the builtin spec proved every stage with `contains: ["approved"]`, so six one-line files completed the whole chain while a genuinely APPROVED record was refused, and every command the runbooks taught (`workflow.py create --builtin X --project-root R`) exited 2 because argparse only accepted the flag before the subcommand. The gap is a single class: a rule with two owners, the prose one never executed. The fold gives the order to the kernel's spec and each verdict to the gate that already owned it (run_experiment, create-record, story_quality, sync-story-qr), routes the dispatcher through them, scopes a run to one story, and retires the prose.
- **Hypothesis:** H-150: "chain_handoff_accuracy == 1.0"
- **Measurement Metrics:** chain_handoff_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit plus the pre-change tree extracted from PREFIX_REV with `git archive` (the control arm). Procedure: `scripts/bench/bench_chain_handoff.py` runs fourteen probes, each driving a shipped surface: (1) the dispatcher, CLI and spec exist; (2) docs/bmad is gone; (3) no live surface cites the retired tree; (4) the spec validates; (5) every stage's evidence is `command`, not a keyword; (6) the documented CLI form (`create --builtin … --project-root R`) works and `{python}/{project-root}/{metodoloji-root}/{slug}` expand to real paths; (7) two story runs coexist with no shared snapshot; (8) six stub records containing "approved" satisfy no stage; (9) a NOT-approved record is refused; (10) an out-of-order `complete` is refused; (11) one run cannot spend another's evidence; (12) tier 2 routes experiment → story; (13) the three audits pass; (14) the templates' status words equal the schema owner's. Control: `--broken` runs the same fourteen probes against the pre-change tree; it must score below the threshold. Reproducibility: stdlib only, deterministic, no network.
