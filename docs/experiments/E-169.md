## Experiment: E-169 — A test pays for its boundary once, not twice

- **Date:** 2026-11-15
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Measured 2026-11-15 on this tree: after E-167 the suite cost 456 s, and two tests were paying twice for one measurement. (1) THE RE-RUN CONTROL ARM: test_keyless_audit.py drove the plugin audit seven times — four direct _audit_without_key() spawns, a wholesale loop over bench.PROBES, and a second bench.run() under BROKEN. Every drive spawns the audit (~23 s), and the control arm is the bench's own --broken, which the gate runs as the rule-7 control, so the same tree was measured twice in pytest. (2) THE OVERSIZED FIXTURE: test_tar_member_limit wrote 200,005 tar members (27 s) and test_validate_methodology_chain_bounds_limits_iterations wrote 1,100 files to assert 'over the limit, fall back to the conservative dest'. The shipped constant is a BOUND — the behaviour under it is identical at any size, so patching it down exercises the same branch at a size nobody needs to pay for on every run. Neither was a wrong claim; both were the right claim at a cost the loop did not need.
- **Hypothesis:** H-169: "loop_cost_accuracy == 1.0"
- **Measurement Metrics:** loop_cost_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit plus the module as it shipped at HEAD~1 (git show), which keeps the control arm measuring the real pre-fix source rather than a snippet written to match. Procedure: scripts/bench/bench_loop_cost.py gains two probes, each derived from source rather than listed (E-039). (1) test_keyless_audit.py drives the plugin audit at most once — counted by AST over all four drive shapes (a direct _run_audit/_audit_without_key call, a bench.run(), and a loop over bench.PROBES), not by text, because a docstring that names bench.run() is not a call. (2) No test file builds an archive or story fixture sized from a shipped LIMIT constant unless it monkeypatches that constant down first — every test file under the four test roots is enumerated by glob, and each range(UPPER + n) is checked against the module's own setattr calls. The repair makes test_keyless_audit.py share one bench.run() across all five tests, patches ARCHIVE_MAX_MEMBERS to 5 (10 members) and MAX_STORY_COUNT to 5 (10 files). Control: --broken evaluates the same two probes against the pre-fix source and must score below the threshold. Reproducibility: stdlib + ast + git, offline, deterministic.
