## Experiment: E-133 — Memoising the glob parser buys 1.6-2.0x on the freshness scan

- **Date:** 2026-11-12
- **Status:** completed
- **Record Kind:** experiment
- **Theory:** E-132 measured the freshness scan calling glob_to_regex 114,109 times over 248 distinct patterns and authorised repairing that function; the repair landed as one functools.lru_cache on a pure string function, plus a cache_clear inside reset_cache so that function still drops every per-process cache. This record measures whether the memo actually pays, and refuses a speedup that came from anywhere else: each cell times the scan with the memo and without it (the decorated function __wrapped__, i.e. exactly the pre-fix work), in the same process, back to back, over the same corpus. The claim is a ratio rather than a wall time because wall time on this machine drifts by a couple of seconds between runs while the ratio does not. What this record deliberately does not claim: it does not bring THIS repository under its 10s hook budget. Profiling after the fix puts 16.6s of the remaining ~19s inside thirty-one subprocess version-control calls (changed_since asks one full diff per distinct witness point, and one diff here spans 1,794 files). The memo removes the re-parsing, not the per-point diffing; that is a separate repair and this record names it instead of implying the budget is met.
- **Hypothesis:** H-133: "freshness_scan_speedup_rate >= 0.999"
- **Measurement Metrics:** freshness_scan_speedup_rate >= 0.999
- **Experiment Design:** Three independent trials of one operation. The scan is _freshness_chain_row over this repository record corpus; it does not branch on adapter mode or message form, so cells are replications rather than different surfaces, and the census says so instead of manufacturing axes. Each cell times an uncached scan and a cached scan of the same corpus, back to back, and scores the ratio: a cell reaches the claim at 1.5x or better, so the rate is the share of trials that reach it. The control runs the identical bench with the memo unused on both sides, which reproduces the pre-fix state: its ratio is the defect, it must land near 1.0, and it therefore cannot clear the claim. Timing is wall clock around the row only; import cost and a warm-up scan are excluded so no cell is charged for module loading.
