## Experiment: E-146 — The plugin config has one owner

- **Date:** 2026-11-13
- **Status:** completed
- **Record Kind:** contract
- **Theory:** A configuration file that two readers load from two different paths, and that duplicates a second file's keys, has no single owner: the merge order is the only thing keeping the values coherent, and any reader that skips the merge silently disagrees with the ones that do. The plugin shipped exactly that shape — bmad/config.toml (path defaults), bmad/config.user.toml (personal), custom/config.toml (gate policy), plus an always-absent custom/config.user.toml. Two of bmad/config.toml's eight keys (core.output_folder and all three modules.bmm paths) were byte-identical copies of keys in custom/config.toml, and the hook engine read custom/config.toml directly while resolve_config.py merged all four. This is the duplicate-owner class E-047/E-048 closed for the version manifests and E-145 closed for the record-status vocabulary: two copies that agree only by hand.
- **Hypothesis:** H-146: "config_equivalence_accuracy == 1.0"
- **Measurement Metrics:** config_equivalence_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit, plus a baseline fixture captured from the PRE-consolidation tree (scripts/bench/fixtures/config-baseline.json — the full merged dump, the documented targeted read, and the eight live hook-engine reads). Procedure: scripts/bench/bench_config_consolidation.py runs six checks — (1) the plugin ships exactly one team config and no legacy copy, (2) the full merged dump equals the baseline, (3) the targeted --key read equals the baseline, (4) every hook-engine mode (code/quality/deploy gates, blackboard on/off + backend, three freshness knobs) equals the baseline, (5) no key is declared in both the owner and a legacy file, (6) the owner wins when both files exist and the legacy file is read only when the owner is absent. Control: --broken drives the PRE-FIX resolver read from git HEAD against the new tree, so the control is the old reader rather than a paraphrase of it; it also asserts the old duplicate keys and the old bmad/config.toml requirement. Reproducibility: stdlib only (tomllib, subprocess, tempfile), no network, deterministic.
