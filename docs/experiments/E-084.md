## Experiment: E-084 — `/metodoloji:add` turns a source into a registered external context

- **Date:** 29.10.2026
- **Status:** completed
- **Theory:** E-075 through E-083 built the external-context registry, a shared deterministic finder and a resilient, label-aware scoring contract, and the research methodology already tells an agent to register reusable analysis. The workflow still has no single entry point for the user's actual request ("analyze this repository / these docs / this PDF and add it"): every surface expects the agent to improvise the same steps (choose a slug, copy the template, update the README index, validate the completed entry), and nothing mechanical checks that a "registered" entry is complete or indexed. That gap produces the failure class the earlier experiments kept repairing: an entry that is half-template, unindexed, or silently skipped. A slash command backed by a stdlib-only scaffold/validate/audit tool makes the mechanical half deterministic while leaving the analysis to the agent.
- **Hypothesis:** H-084: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the current consistency bench and its `--broken` seeded-defect control. Add a contract check that the shipped slash command, the scaffold/validate/audit CLI, the user-facing command surfaces (README, both agent guides) and the Hermes registration agree, and seed removal of the CLI reference from the command in broken mode. Add tests for source classification (repository URL, docs URL, PDF/Markdown path), slug derivation, non-destructive prepare, template-placeholder validation, reviewed-status enforcement, idempotent README index updates, and registry audit findings. Reproducibility is local and offline.
