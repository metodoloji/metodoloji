## Experiment: E-165 — The freshness row carries every key its consumers read

- **Date:** 2026-11-15
- **Status:** completed
- **Record Kind:** experiment
- **Theory:** Measured 2026-11-15 on this tree: E-160 deleted guard._record_freshness's hand-rolled anchor and delegated to freshness.annotate, the plane's single owner. The guard's returned row is read by two call sites that do not read the same fields — guard._freshness_chain_row indexes verdict/reason, and scope_gate.scope_advisory indexes fresh['commit'] at line 96 for its remedy line. annotate had the commit in hand but did not return it, so the delegation silently dropped a key the write path indexes unconditionally: any APPROVED record whose scope matched and read STALE raised KeyError: 'commit' on the write path — a crash where a warning was meant. Nothing caught it because the guard's own test stubs _record_freshness with a hand-built dict that happens to carry the key, and because E-160's bench measured the anchor, not the row's field contract.
- **Hypothesis:** H-165: "freshness_row_contract_accuracy == 1.0"
- **Measurement Metrics:** freshness_row_contract_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit. Procedure: scripts/bench/bench_freshness_row_contract.py derives both sides from source rather than from a hand list (E-039). It parses freshness.annotate's return dict for the produced key set, parses every assignment whose value is a call to _record_freshness or annotate for the consumer bindings, and collects every string subscript on those bindings across guard.py and scope_gate.py. Probe 1 asserts no consumer indexes a key the producer does not return. Probe 2 calls the live annotate on a real record and asserts the returned row carries every consumed key. The repair adds commit to annotate's returned dict. Control: --broken drops commit from the produced set and must score below the threshold. Reproducibility: stdlib + ast, offline, deterministic.
