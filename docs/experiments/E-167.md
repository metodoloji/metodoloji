## Experiment: E-167 — The development loop stops re-measuring the same input

- **Date:** 2026-11-15
- **Status:** completed
- **Record Kind:** experiment
- **Theory:** Measured 2026-11-15 on this tree: one full test run costs 607 s, and most of it is the same measurement repeated. Four families. (1) DUPLICATE AUDIT SPAWNS: bench_keyless_audit ran the full plugin audit (about 20 s each) once per probe, but three of its four probes measure the SAME invocation — same tree, same empty HOME, same flags — and test_keyless_audit.py then spawned it four more times and called bench.run() twice: twelve audit runs for two distinct inputs, 245 s of the suite's 607. (2) SUITE-IN-SUITE: bench_methodology_contract runs the whole pytest suite as its measurement (581 s) and bench_consistency's falsifier runs it again, so run_all.py runs the suite twice on top of the dedicated test job. bench_fixture_repair adds a third copy: its measurement IS the six benches E-166 repaired, which run_all.py runs anyway. (3) CI TRIPLICATION: quality.yml runs pytest -q on ubuntu and again on windows, and the benches job ran the suite-running benches a third time. (4) THE BOUNDARY FIXTURE: test_block_boundary_is_arithmetic_not_a_decision built 100 commits + 100 annotated tags + a push (56 s) to assert position 100 == 0.2.0, which is a pure function of the position. None of this measured anything the other runs did not.
- **Hypothesis:** H-167: "loop_cost_accuracy == 1.0"
- **Measurement Metrics:** loop_cost_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit. Procedure: scripts/bench/bench_loop_cost.py asserts five properties, each derived from source rather than listed (E-039). (1) bench_keyless_audit has at most two _run_audit call sites, one per distinct input shape (keyless, keyed); a third is a duplicate even though the cache makes it free. (2) test_keyless_audit spawns the audit zero times directly — it drives the bench's probes, so one run is shared. (3) Every bench that re-measures another surface is dropped by run_all.py --skip-full-suite, the flag CI passes. Two shapes count: a bare pytest run (the contract bench and the consistency falsifier), and a bench that declares META_BENCH = True because its measurement IS other benches' measurements (bench_fixture_repair). The second shape is a declaration, not a source-text guess: a spawn and a docstring are indistinguishable to a regex, and a hand list rots (E-039). (4) CI runs the full suite at most twice (one per platform) and the benches job passes --skip-full-suite. (5) The 0.2.0 boundary is asserted from versioning.auto_version directly rather than by building a 100-position history. The repair adds an audit-result cache and a single _keyless_audit() call site, adds --skip-full-suite to the runner and CI, declares bench_fixture_repair meta, and rewrites the boundary test as arithmetic. Control: --broken reports the pre-fix shape for every probe and must score below the threshold. Reproducibility: stdlib + ast, offline, deterministic.
