## Experiment: E-060 — Confine the evidence read to the project root, in the one matcher

- **Date:** 17.10.2026
- **Status:** completed
- **Theory:** E-059 measured the hole E-058's Known Gaps and QR-019's follow-ups had both deferred: the evidence plane reads and completes on artifacts OUTSIDE the project root. `artifact_matches` builds its path with `os.path.join(project_root, raw_path)`, which returns the declared path unchanged when it is absolute and normalises `..` segments, so `../outside.md`, `docs/../../outside.md` and an absolute path were all read in full — and on the session edge (the advisory runs at SessionStart, unattended) the verdict was printed as `CURRENT`. The completion gate accepted the same predicate, so such a witness could be recorded in the first place. A run's evidence is a claim about ITS OWN project, so the fix is containment in the ONE matcher that both the completion check and every re-derivation already share (E-056's doctrine): a path that resolves outside the root is never read. Measured honestly, that means the read surfaces answer UNKNOWN — "cannot be established" — never CURRENT (which would mean the outside file was read) and never STALE (which would mean it was read and turned into a definite negative); and the completion path, being a gate rather than a view, REFUSES with the cause named. The check is resolved with `realpath` on both sides, so a symlink or junction inside the project that points out of it is an escape like any other, and a candidate the glob reaches through such a link counts exactly like a candidate past the read budget: it turns a negative answer into UNKNOWN instead of a STALE.
- **Hypothesis:** H-060: "escape_read_rate <= 0.0"
- **Measurement Metrics:** escape_read_rate <= 0.0 (with `escape_accepted_rate <= 0.0` carried as the completion-gate threshold and false_alarm_rate as the paired control, all parsed from the same bench output)
- **Experiment Design:** The SAME bench, oracle and fixture families as the E-059 baseline — `scripts/bench/bench_workflow_evidence.py`. The only difference is what the plane does with a path that leaves the root: the declared-path check runs before anything is read, every glob candidate is resolved and skipped when it lands outside (counted, so a skip can only degrade the answer to UNKNOWN), and the completion path receives the same None result, which it already maps to a refusal. Controls unchanged: the expectation vector (`trials: stale=12 current=12 unbounded=6 escape=9 gate=3`) fails a fixture that stopped producing trials; `false_alarm_rate` fails a "mark everything UNKNOWN" non-fix (an in-root, satisfied artifact must stay CURRENT — and a nested in-root `deep/**/*.md` glob still completes and reads CURRENT); `--baseline` reproduces the pre-fix delivery semantics and must return 1.0 on all four defect metrics, which is this bench's own negative test on the fixed tree. Procedure — `python scripts/bench/bench_workflow_evidence.py`.
- **Sample Size n:** 9 (escape read trials; the gate bucket's 3 trials are reported as `escape_accepted_rate` and the gate parses the denominators from the bench output)
- **Code Scope:** bmad/workflow/evidence.py, bmad/tests/test_workflow.py, scripts/bench/bench_workflow_evidence.py
