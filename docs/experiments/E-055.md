## Experiment: E-055 — A workflow stage's artifact evidence stops being true, and the run keeps advancing on it

- **Date:** 17.10.2026
- **Status:** REJECTED
- **Theory:** The stale-context line closes one plane at a time. E-052/E-053 measured and fixed the BOARD plane (a hand-off signal whose claim the code moved past was delivered as live work). The same class sits one plane over, on the workflow kernel: a stage's evidence is checked exactly ONCE, at `complete` time (`bmad/workflow/engine.py::_check_evidence` — the artifact exists and carries the declared tokens), then never re-read. The run's state records the stage as `completed` and `next` keeps computing forward from it. So a foundation the workspace has moved past — the artifact deleted, the declared token removed, the glob match gone — is still delivered as satisfied work, and the agent obeys it. This is the plan's F-13, marked and not owned by E-053 (§10): "an `artifact` proof keeps counting as proof after the artifact changed". The report that opened the line is the same one: "The failure mode we hit most isn't lost context, it's stale context. Yesterday's decision is still in the handoff file, and the agent obeys it after the code has already moved on."
- **Hypothesis:** H-055: "stale_evidence_rate <= 0.0"
- **Measurement Metrics:** stale_evidence_rate <= 0.0 (with false_alarm_rate reported as the control metric)
- **Experiment Design:** Inputs — `scripts/bench/bench_workflow_evidence.py`, which builds a throwaway project per trial with the workflow kernel's own public API (`bmad.workflow.engine`: `create` → `complete` → `status`/`next_stage`) and probes TWO read surfaces per run (the status view and the computed-next view); no dependency on this checkout, no gate key, stdlib only. Four stale fixtures, each moving the workspace one way an artifact evidence can stop holding: the declared token removed, the artifact file deleted, the artifact replaced with unrelated content, and a glob evidence (`logs/*.md`) whose satisfying match is removed. Four current fixtures, the paired control: untouched, appended-to (token kept), rewritten-with-token (content changed, predicate holds), and a glob evidence whose satisfying match was deleted while another matching file still carries the token. n = 8 stale + 8 current trials. The EXPECTED verdict is computed by an ORACLE that never imports the module under test — `pathlib.glob` + `str.count` re-applying the stage's own declared predicate over the fixture tree (a second implementation: the engine uses `glob.glob` + a token sum). A trial leaks when the oracle says the predicate no longer holds and the surface delivers the completed stage as anything other than STALE (no verdict reads as satisfied); it is noise when the predicate holds and the surface says STALE. Controls — the oracle's expectation vector is printed as `trials: stale=8 current=8`, so a fixture that stopped producing both classes fails loudly instead of scoring 0; the paired false-alarm rate fails a "digest changed ⇒ stale" non-fix, which is exactly the design the `rewritten-with-token` and `glob-other-match` fixtures reject. `--baseline` reproduces the pre-fix delivery semantics (a surface with no evidence dimension) and must return 1.0 — the bench's own negative test. Reproducibility — deterministic, no network, each run under a fresh `mkdtemp`.
- **Sample Size n:** 16 (8 stale + 8 current trials; the gate parses the denominators from the bench output)
- **Code Scope:** scripts/bench/bench_workflow_evidence.py, docs/experiments/E-055.md
- **Lineage:** E-053 (the freshness plane: witness + derived, three-valued verdict — this record carries its doctrine "derive, never store" onto the workflow evidence plane, and supplies the baseline that plane's fix must close), E-054 (the same plane re-measured at the landed commit: the CASCADE_INVALIDATION path and the "code moved, content identical" lesson), E-052 (the measured baseline failure on the board plane — measured=1.0 REJECTED; the method (throwaway fixture repo, oracle that never imports the module under test, paired false-alarm control, `--baseline` negtest) is re-tread here), E-037 (the class itself: an artifact asserting a fact nobody measured — here, that a recorded completion is still true)
