## Experiment: E-020 — The QR-feeder audit must cover every feeder BRIDGE surface, not 9 of 16

- **Date:** 10.10.2026
- **Status:** completed
- **Theory:** The 33 BRIDGE surfaces partition cleanly and the tree proves it:
  every `custom/*.toml` that cites `dev-skill-to-methodology-bridge` either
  carries a VERIFY step and a "produce a record" BRIDGE (17 producers) or
  lacks it and says "does not produce an independent methodology record" (16
  feeders). E-018 pinned the producer half; the feeder half was left narrow.
  `check-plugin.sh` §2 iterates `QR_FEEDERS_TOML` to demand the bridge
  reference and the `docs/quality/QR` target on each feeder, but that list
  named only 9 of the 16 — the seven gds feeders (`gds-test-automate`,
  `gds-test-design`, `gds-test-framework`, `gds-test-review`,
  `gds-e2e-scaffold`, `gds-performance-test`, `gds-playtest-plan`) were never
  read here. §2b still proved their BRIDGE *merges*, and `check-custom.sh` §5
  names four gds *producers*, but nothing checked that a gds feeder actually
  points its findings at a QR record — the half of the feeder contract the
  audit exists for. Root cause is the same "guard is only as wide as its
  hardcoded tuple" class E-002/E-017/E-018/E-019 named. The fix derives the
  feeder set from the tree on two independent signals (the feeder phrase and
  the absence of a VERIFY step, which agree across all 33 surfaces), widens §2
  to all 16, and pins the list so a feeder cannot silently drop out of the
  audit.
- **Hypothesis:** H-020: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit.
  Procedure — run `python scripts/bench/bench_consistency.py`, which evaluates
  independent doc/code-consistency claims and prints
  `consistency_accuracy=(x/y)`; one new check pins the E-020 claim (it parses
  §2's `QR_FEEDERS_TOML`, derives the tree's feeder set from the feeder phrase
  while asserting the phrase and the absence of a VERIFY step agree on every
  BRIDGE TOML, demands the two sets are equal, and re-checks the bridge
  reference + QR target on each), plus the regression tests by name. Control —
  the bench's own "pytest suite green (falsifier)" check pins that the code
  under test still passes the full suite, which now includes two new tests in
  `scripts/tests/test_selfcheck_scripts.py` (the bench check returns `None` on
  this tree; §2's list is asserted to contain the seven gds feeders). The probe
  is falsifiable by construction: deleting the gds-test line from
  `QR_FEEDERS_TOML` turns the new bench check red
  (`§2 QR_FEEDERS_TOML != tree feeders (missing […gds-test-*…])`). Reproducibility
  — stdlib only, no network, deterministic: the check reads the tree and script
  as they are, and a fixed tree yields a fixed x/y; the measurement reports the
  tree as it is, independent of this record (E-001).
