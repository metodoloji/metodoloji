## Experiment: E-151 — The contract page is retired; every rule keeps its owner

- **Date:** 2026-11-14
- **Status:** completed
- **Record Kind:** contract
- **Theory:** docs/methodology.md was the page every surface was pointed at: 42 customize.toml persistent_facts entries, 34 activation steps, 15 SKILL.md pointers, three audit checkers, a plugin-root sentinel, a trust-policy surface and a stage table. It stated no rule of its own — it named owners. That made it the same defect class E-150 closed one directory over: a document that restates what code already decides, so the code and the page drift independently and only the page is read. Two of its sections had no code behind them at all (a Modes A/B/C/D table no surface implements, and a trust-boundary sentence carried identically by ten other shipped files). Its stage table was pinned to the spec by a test, which is the tell: the page needed a guard to stay true, while the spec needed none because it IS the source. The retirement replaces the page with the artifact each surface is actually bound to — the chain spec, or the record template that surface produces — and adds one probe that fails if any live surface points at the retired path again.

- **Experiment Design:** Inputs: the plugin tree at this commit plus the pre-change tree extracted from PREFIX_REV with git archive (the control arm).
