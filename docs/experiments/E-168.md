## Experiment: E-168 — A bench writes its samples where it is told

- **Date:** 2026-11-15
- **Status:** completed
- **Record Kind:** experiment
- **Theory:** Measured 2026-11-15 on this tree: run_all.py passes --samples <tempdir> so a CI run never rewrites the committed evidence under docs/experiments/. Three benches ignored the VALUE — they declared the flag, then wrote to a hard-coded record path or a BENCH_SAMPLES env var instead: bench_freshness_pathspec.py to E-134/raw/samples.jsonl, bench_freshness_cache.py to E-133/raw/samples.jsonl, and bench_freshness_budget.py to <record>/raw/samples.jsonl. The effect was measured, not inferred: running the bench population rewrote E-134's committed samples (four lines appended for E-160..E-163) and the change had to be reverted before commit. E-162's Known Gap 4 recorded the symptom as a caveat; this record fixes the cause, because a measurement plane may not overwrite its own evidence — the evidence IS what the gate recounts, so a rewritten samples file can make a claim look measured that no run produced.

Procedure: scripts/bench/bench_samples_isolation.py asserts two properties, both derived from source rather than listed (E-039). (1) Every bench that declares --samples reads the value: args.samples, a shared _samples_path() helper, or a sys.argv scan for --samples <path> / --samples=<path>. (2) No bench can write only committed evidence: a bench whose write target is a record's raw dir must consult the flag first. The repair makes the three benches parse the flag value before falling back to BENCH_SAMPLES and then to the record path. Behavioural proof: running bench_freshness_pathspec.py --samples /tmp/probe_samples.jsonl leaves E-134's samples byte-identical (sha256 7c0c0b58… before and after) and writes 3069 bytes to the temp path. Control: --broken reports the pre-fix shape (the three benches) and must score below the threshold. Reproducibility: stdlib + ast, offline, deterministic.
