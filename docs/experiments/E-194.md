## Experiment: E-194 — The chain gate names the defects its excerpt withheld

- **Date:** 21.11.2026
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Found live on this tree, 2026-11-21, by pointing chain-gate's schema stage at an attested record with twelve defects: 'E-900.md: schema check failed — FAIL: … (contract)  - missing or placeholder field Status … - missing or placeholder field Experime'. Five and a half of twelve defects, cut mid-word, with no sign that anything was withheld. The stage blocked while hiding most of the reason, so the agent fixes what it can see, reruns, and sees the next few — the gate knows the whole fault list and shows half of it. Both failure paths carried the same out[:300] (the schema checker and the experiment verifier). A diagnostic is not a value to be clipped at an offset: a fault list is lines, so the honest bound keeps whole lines and names the count it dropped.
- **Hypothesis:** H-194: "gate_excerpt_bound_accuracy == 1.0"
- **Measurement Metrics:** gate_excerpt_bound_accuracy == 1.0
- **Experiment Design:** Inputs: a committed record copied into a throwaway tree in two shapes — every required field stripped, so create-record.py --check prints a long multi-line fault list, and a single invalid Status value, so the fault list is one short line. Procedure: scripts/bench/bench_gate_excerpt_bound.py drives the shipped chain-gate schema stage and runs ten probes — the lines shown are verbatim lines of the checker's output, the marker names a positive hidden count, shown plus hidden equals the checker's total line count, the marker sits on its own line, the kept body stays inside the 300-char bound, a short fault list prints verbatim with no marker, the last shown line is a complete checker line (never a mid-word fragment), the stage still fails closed, both failure paths call _excerpt, and the raw out[:300] slice is gone from the source. Control: --broken runs the same probes against the pre-change tree at git 0953f6b (which predates E-192 and E-193; none of the three changes is in that tree), whose excerpt is out[:300]. Reproducibility: stdlib plus git only, offline, deterministic; each probe runs in its own process.
