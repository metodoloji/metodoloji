## Experiment: E-198 — The sprint line cuts on a part boundary and counts what it withheld

- **Date:** 2026-11-22
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Found live on this tree on 2026-11-22, driving modules.state.format_sprint_line over a realistic board (8 in-progress, 5 review, 3 done, one lagging epic). The formatter built its parts and then sliced the finished sentence at 197 characters, so the session-start inject and the stop/orient renderings of the same line delivered 'sprint: 8 in-progress (...); 5 review (...); 3 done (2-1-hero, 2-2-nav, 2-3-foot); ⚠ epic-2: stories all done — epic …'. The discrepancy survived and its action did not: 'roll up to done + run the retro' was cut off, and any ⚠ past the cut vanished behind one bare '…' with no count. A part is the semantic unit of this line (a status group or one epic mismatch); a cut inside one turns a report into a fragment, and a bound that hides its remainder is the same silent claim E-195…E-197 removed from the neighbouring surfaces. The fix bounds by parts, names how many were withheld, and leads with the ⚠ parts so a board wide enough to overflow still shows its discrepancies.
- **Hypothesis:** H-198: "sprint_line_accounting_accuracy == 1.0"
- **Measurement Metrics:** sprint_line_accounting_accuracy == 1.0
- **Experiment Design:** Inputs: a scratch project root built per run (the working copy for the claim, git archive of PREFIX_REV for the control) holding only a sprint-status.yaml under docs/development/native, which the bench writes. Ten probes: a wide board keeps both epic warnings whole including their action, the warnings lead the line, the withheld parts are counted, the 200-character bound holds for that board and for an extreme one (8 in-progress, 59 done, six lagging epics), a fitting line prints with no marker, a status-only board still lists its groups, one part wider than the whole line keeps its identity and counts the part after it, the shipped audit.session_start inject carries the whole action, and the formatter no longer slices the finished line. Procedure: each probe writes its board, runs format_sprint_line (or session_start) in-tree in its own process, and reads the line it emits. Control: --broken repeats this against E-197's commit bad08ce, which slices the finished line at 197 characters — 4/10, the four passes being the behaviours the bound did not change (the bound length itself, a fitting line unmarked, a status-only board, and the wide board staying under 200). Reproducibility: stdlib plus git, offline, deterministic.
