## Experiment: E-063 — A completed command stage is delivered with no verdict at all

- **Date:** 17.10.2026
- **Status:** REJECTED
- **Theory:** The evidence plane classifies `artifact` completions and, since E-056, derives a witness for them. `command` evidence — "this argv exited 0" — was deliberately left unwitnessed on the stated grounds that a command's result is recorded history rather than a claim about the workspace (rule 5), and the plane organised around that by SKIPPING such stages: `verify` continues past any completed stage whose witness is absent and whose spec kind is not `artifact`. The consequence is not neutrality but silence. A stage whose proof was a green test suite is delivered as completed work with `evidence: {}`, `evidence_health.total: 0`, `stale_evidence: []` — identical to a stage that passed against this very code, whether the suite ran five minutes or forty commits ago, and no surface says otherwise. That is the same shape the bench has scored as a defect on every other plane ("a surface that carries no verdict delivers the stage as satisfied"), and it is the last named piece of the plan's F-13: `command` evidence is the one claim in the plane that cannot be re-derived by looking, so the honest answer has to be a comparison — the completion dated to the tracked code state the command was run against — rather than nothing at all. The oracle is the one the board plane already dates its decisions to (E-053/E-054 records a commit and a scope hash): git, read once and bounded, with an unavailable oracle answering UNKNOWN rather than a guess.
- **Hypothesis:** H-063: "command_silence_rate <= 0.0"
- **Measurement Metrics:** command_silence_rate <= 0.0 (with `command_hold_rate <= 0.0` carried as the paired control — a command completion whose tracked code state did NOT move must answer CURRENT — parsed from the same bench output)
- **Experiment Design:** Inputs — `scripts/bench/bench_workflow_evidence.py`, extended with a fifth bucket. Command bucket: 2 movement fixtures x 3 read surfaces (6 trials) plus 3 control trials. Each fixture's project is a real git work tree (`git init` + one commit) because the code-state oracle is git; the `check` stage completes on a command (`<python> -c "print('ok')"`, rc 0) and the tracked tree then moves in one of two ways, covering both halves of the fingerprint: a new COMMIT (HEAD moves) and a DIRTY EDIT of a tracked file (HEAD stands, the working tree moves). The defect is a surface that delivers the completed stage with no verdict (or as CURRENT) after that movement — nothing distinguishes "the suite passed against this code" from "the suite passed long ago" without dating, and the honest answer is UNKNOWN with the reason. Control: the same fixture with the tracked tree left alone must answer CURRENT (3 trials) — it fails a "mark every command UNKNOWN" non-fix, which would make the verdict worthless; on the unfixed plane the control fails by silence too, which the bench reports rather than hides. Procedure — `python scripts/bench/bench_workflow_evidence.py` (the bucket needs `git`; the bench refuses to run rather than silently skipping it).
- **Sample Size n:** 6 (command silence trials; the control's 3 trials are reported separately as `command_hold_rate` and the gate parses the denominators from the bench output)
- **Code Scope:** scripts/bench/bench_workflow_evidence.py, docs/experiments/E-063.md
- **Lineage:** E-062 and E-060 (the two planes hardened before this one, and the doctrine they share: a claim the plane cannot establish answers UNKNOWN with the reason, and a witness is what makes a completion falsifiable), E-058 (the read-budget doctrine this bucket inherits: the code-state probe is one bounded call per read pass, not one per run), E-061 and E-059 (the sibling baselines on the same bench — measured defects on surfaces that ran unattended), E-056 (the rule that made silence look principled — it declared `command` and `note` evidence "recorded history, not claims about the workspace": true of a note, and exactly what left a command's result undated), E-053 (the board plane's own answer to the same question: date a recorded decision to the code state it was true in), E-055 and E-057 (the bench's earlier REJECTED baselines whose scope this draft re-treads, so their lesson is carried: a bucket needs a paired control, and "no verdict" is a false success)
