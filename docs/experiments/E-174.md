## Experiment: E-174 — The gate's own edges stop lying

- **Date:** 2026-11-16
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Measured 2026-11-16 while auditing a real Agently session with this plugin. Four edges of the shipped engine reported something that was not true, and each was reproduced live. (1) `deploy_gate.DEPLOY_CMD_RE` matched the bare word `deploy` anywhere in the command text, so a read-only command that merely named `deploy/docker-compose.yml` was blocked with "Deploy blocked: 1 story(s) lack Production Readiness (PR) record" — the story being edited had the word in its own path. (2) `bash_targets` turned every quoted dotted token into a write candidate under the fail-closed tail, so reading a board key (`b['epics.agently']`, inline `-c` or stdin) was denied as "No approved experiment record for epics.agently". (3) `freshness.classify`'s same-commit dirty-tree branch counted every dirty file against a claim that declares no Code Scope, while its own commit-moved branch says an unscoped record has "nothing to stale"; a tracked `.metodoloji/logs/hook-audit.log`, rewritten by every hook, therefore left SP-001 permanently STALE. (4) `guard._prior_attempts` counted substring hits over the whole audit trail, so a first denial on a one-character target reported "This is attempt #59 on the same target". (5) `skeleton.install` never kept runtime state out of git: `.metodoloji/` (sqlite WAL, logs, locks) was committed in the observed project, which is what made (3) permanent.
- **Hypothesis:** H-174: "gate_edge_accuracy == 1.0"
- **Measurement Metrics:** gate_edge_accuracy == 1.0
- **Experiment Design:** Inputs: the shipped engine modules (`deploy_gate`, `bash_targets`, `freshness`, `guard`, `hooks/scripts/skeleton.py`) and the pre-fix tree at git 44f7bbc. Procedure: `scripts/bench/bench_gate_precision.py` runs each probe in its own process against the tree under test — building throwaway git projects where the probe needs a work tree — and states the expected verdict once, in the bench. Seventeen probes cover the five edges: deploy-command shapes, inline-code shapes, freshness shapes, attempt-counter shapes, installer shapes. Control: `--broken` runs the same probes against 44f7bbc, where each repaired edge still reports the false value. Reproducibility: stdlib only, offline, deterministic (fresh temp project per probe; the git fixture commits a fixed tree).
