## Experiment: E-154 — Every shipped audit is bound to a surface CI runs

- **Date:** 2026-11-14
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-152 retired docs/runtime-security-coverage.md and named the class in its Known Gaps. One member of that class survived: scripts/check-runtime-coverage.py ships, has no test, is invoked by nothing (its only mention anywhere is a historical experiment record), and its first read is the retired doc, so running it raises FileNotFoundError. That is TD-016's declared-but-unbound mechanism, one file large: an audit nobody runs cannot catch the drift it exists for, and a shipped audit whose subject is gone is a live instruction to a crash. Deleting the one file is not the hardening: the audit family must be reachable from the surfaces CI actually runs, and the rule itself must run in CI, or the next orphan is invisible in exactly the same way.
- **Hypothesis:** H-154: "audit_binding_accuracy == 1.0"
- **Measurement Metrics:** audit_binding_accuracy == 1.0
- **Experiment Design:** Inputs: the plugin tree at this commit plus the pre-change tree extracted from PREFIX_REV (ac0c05b) with git archive for the control arm. Procedure: scripts/bench/bench_audit_binding.py runs seven probes over the shipped tree: (1) the audit family is DERIVED from scripts/check-*.sh|py, never hand-listed; (2) every family member is named by a surface CI runs (the quality workflow or check-plugin.sh), with comment lines stripped first so a mention in a comment cannot bind an audit; (3) every audit a runner names exists on disk, so the runner carries no dead instruction; (4) the retired auditor and its subject doc are both gone, leaving no half-dead pair; (5) no shipped audit names the retired subject; (6) check-plugin.sh itself runs in CI, so runner reachability is transitive; (7) this bench runs in CI, because a binding rule nobody runs is the same defect one level up. Control: --broken runs the same seven probes against the pre-change tree, which still ships the orphan, and must score below the threshold. Reproducibility: stdlib only, deterministic, no network.
