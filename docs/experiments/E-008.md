## Experiment: E-008 — Make corrupt-state detection agree with the storage path, and gate `create` on it

- **Date:** 08.10.2026
- **Status:** completed
- **Theory:** E-005's Known Gap, verbatim: "a future read path not routed
  through `list_runs`/`status`/`next`/`history`/`flag`/`resume` might still
  swallow a corrupt file." Behavior probing found two live paths, both rooted
  in one seam — the corrupt detector and the storage disagree, and the
  mutator-in-chief never consults the detector. (1) `store._state_path`
  SANITIZES the slug (non `[alnum._-]` → `_`) but `engine.state_is_corrupt`
  builds its probe path with the RAW slug: a run created as "my run" lives at
  `my_run.state.json`, so the detector checks a file that never exists,
  returns False, and `_missing_or_corrupt` falls through to
  `no workflow 'my run'` — probe proves `status`, `next`, `history`, `flag`,
  `block`, `resume` and `complete` (seven commands) swallow a corrupt run that
  `list` honestly names `corrupt: true`. (2) `create` never calls the
  predicate at all: `store.read_state` degrades a corrupt file to `{}` (the
  documented fail-open storage contract), so `existing` is falsy and create
  overwrites the broken-but-possibly-recoverable state with `ok: true` — probe
  proves it clobbers WITHOUT `--force`, the exact silent data loss E-005's
  refusal text warns against. The fix is one agreement: the detector reads the
  storage's own path function, and `create` refuses through the same honest
  refusal the read paths use.
- **Hypothesis:** H-008: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit. Procedure —
  run `python scripts/bench/bench_consistency.py`, which evaluates independent
  doc/code-consistency claims and prints `consistency_accuracy=(x/y)`; two new
  checks pin the E-008 claim (a space-slug's corrupt state is detected through
  the sanitized path and every mutating command refuses over it with the bytes
  untouched, plus test coverage of the seam), and the suite's pytest falsifier
  covers the new regression tests. Control — the bench's own "pytest suite
  green (falsifier)" check pins that the code under test still passes the full
  suite. Reproducibility — stdlib only, no network, deterministic (a fixed tree
  yields a fixed x/y); the measurement reports the tree as it is, independent
  of this record (E-001).
- **Sample Size n:** 59 (informational — the gate parses the denominator from
