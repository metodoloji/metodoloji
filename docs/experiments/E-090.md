## Experiment: E-090 — A command test must not write into the live external-context registry

- **Date:** 30.10.2026
- **Status:** completed
- **Theory:** The Hermes command-resolution test exists to prove that every slash command still resolves its imports when the plugin is loaded as a package. It does that by iterating `COMMANDS` and calling each handler with `docs/experiments/E-001.md`. That argument was harmless while every handler was pure, but `/metodoloji-add` is not: its handler runs `external-context.py prepare` with `--project-root agent_cwd()`, so the test itself creates `docs/research/external/experiments/context.md` in the live plugin tree. The draft is a schema-2 scaffold with placeholders and `Status: draft`, so `external-context.py check --strict` fails immediately after any full-suite run — the registry audit and the pytest suite contradict each other, and the pollution is indistinguishable from a human's abandoned draft. The theory under test is that test isolation is part of registry integrity: a suite that writes into the surface it audits cannot certify that surface, and the consistency bench must be able to see the pollution when it is re-seeded.
- **Hypothesis:** H-090: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the repository consistency bench and its `--broken` seeded-defect control. Isolate `test_commands_resolve_under_package_import` by giving it a `tmp_path` project: create `docs/research/external/_template.md` and `README.md` from the shipped templates, write the source file under `tmp_path`, and monkeypatch `plugin_module.agent_cwd` to return `tmp_path`, so `prepare` writes only into the test's temporary project. Add a bench check that snapshots the live registry's `*/context.md` set, runs that one test, and fails if the test added an entry (or failed); seed removal of the `agent_cwd` monkeypatch in broken mode so the check is falsifiable. Reproducibility is local, deterministic and offline.
- **Sample Size n:** measured from the bench output
- **Code Scope:** hooks/engine/tests/test_hermes_runtime.py, scripts/bench/bench_consistency.py, docs/experiments/E-090.md
- **Lineage:** E-084 (`/metodoloji:add` ships the command and handler), E-089 (one validated registry and a strict audit), E-076 (the shared finder and its behaviorally pinned surfaces) — this record inherits the add command's authoring contract and makes its test stop writing into the registry E-089 now audits.
- **Control Command:** python scripts/bench/bench_consistency.py --broken
