## Experiment: E-085 — An abandoned external-context draft can be archived safely

- **Date:** 29.10.2026
- **Status:** completed
- **Theory:** E-075 through E-084 gave external contexts a registry, a shared finder, a resilient scorer and a single `/metodoloji:add` entry point. The lifecycle only covers create → complete → index. `prepare` is intentionally non-destructive and the repository now carries a half-template draft, so the new `check` fails on a tree where nothing is wrong except an abandoned scaffold. The only escape today is deleting a directory by hand — which removes evidence without a trace and bypasses the index cleanup, leaving a dead link behind. Creating without a supported undo is the same one-way-door class the earlier experiments repaired for records.
- **Hypothesis:** H-085: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Measure the current consistency bench and its `--broken` seeded-defect control. Add a lifecycle contract that scaffolds a draft, archives it through the CLI, asserts the folder moved under the registry's `.archive/` (not deleted), the README index line and placeholder are consistent afterwards, and a reviewed entry refuses archive without `--force`. The registry audit must ignore dot-directories so an archive cannot reappear as a finding. Seed removal of the reviewed-entry guard in broken mode. Add unit tests for the archive path, index cleanup, refusal, missing slugs, and `check` after archive. Reproducibility is local and offline.
