## Experiment: E-195 — A denial counts the issues its bound withheld

- **Date:** 21.11.2026
- **Status:** completed

- **Theory:** Found live on this tree, 2026-11-21, by validating a story with eight acceptance criteria and no metadata: 'AC-001: missing Type field; AC-001: missing Measured field; AC-001: missing Verify field; AC-002: missing Type field; AC-002: missing Measured field'. Twenty-five issues, five printed, no sign that twenty existed. The denial read as a complete explanation, so the agent fixes five, retries, and meets the next five — the gate knows the whole list and shows a fifth of it. story_quality's chain validator used issue[:3] the same way, so a three-issue sample stood in for the chain's whole verdict. This is the silent-omission shape E-194 removed from the chain gate, on the messages that block a write; the repo already has the convention ((+N more)) in the stop report and in the chain gate, and these joins simply were not using it.
