## Experiment: E-036 — A link out of a free zone must not release what it points at: `scratch/link -> ../src` freed the protected tree

- **Date:** 12.10.2026
- **Status:** completed
- **Theory:** E-035's Known Gap named it verbatim: "symlink escapes remain out of reach by design: norm_path is lexical". The design is real (E-006: the guard never touches the filesystem per write), but the consequence is an open write gate: `is_free` decided membership from the SPELLING alone, so `scratch/link -> ../src` (or a root `explore_link.py -> src/main.py`) was freed as a scratch path while the OS resolved every write through the link into the PROTECTED tree — demonstrated before the fix with `is_free("scratch/link/evil.py") == True` on a path that need not even exist yet. The mirror vector closed the measurement half: `scripts/link -> scratch` executed as `python3 scripts/link/bench.py` ran a freely fabricable script that the gate's lexical matcher accepted, because the guard (write) and the gate (run) each read only the spelling. One closure now governs both: the guard re-checks the FILESYSTEM-resolved spelling on the release direction only (utils._resolved_project_rel: two realpath calls when — and only when — a free verdict would be granted; a failed, cross-drive or root-escaping resolution is fail-closed), and the gate resolves the bench target against the measurement host's cwd and zone-checks both spellings, so a refusal is equal to guard-free through a link as well as through a plain path. The reverse direction is unchanged by construction: a link INTO a free zone from a protected dir was already gated lexically, and stays gated.
- **Hypothesis:** H-036: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit. Procedure — run `python scripts/bench/bench_consistency.py`; the new `_check_free_zone_symlink_closure` pins the wiring on every host (resolution seam present in utils.py, is_free consults the resolved spelling, bench_in_free_zone resolves its target, the four regression tests shipped) and adds a live probe where the platform can build a link (symlink, or a privilege-less Windows junction): a link inside `scratch/` pointing at `docs/` must not be freed. The behavioral regressions live in `hooks/engine/tests/test_utils.py` (`test_free_zone_symlink_escape_is_not_free` builds the real links and skips only what the host cannot build; `test_free_zone_symlink_closure_wiring` pins the seam on hosts without link privileges) and `skills/bmad-research-experiment/scripts/tests/test_run_experiment.py` (`test_bench_free_zone_symlink_escape`, `test_bench_free_zone_symlink_closure_wiring`), plus the gate's `--selfcheck`. Controls — the falsifier ran BEFORE the fix: `is_free("scratch/link/evil.py")` returned True (and `is_free("explore_link.py")` True) for a symlinked path into the protected tree; removing the resolution seam turns the bench check red (`utils.py lost the symlink-resolution seam`). The bench's "pytest suite green (falsifier)" check pins the suite. Reproducibility — stdlib only, no network, deterministic; the live probe builds and removes its own link inside the free zone (scratch/), so a fixed tree yields a fixed x/y, independent of this record (E-001).
