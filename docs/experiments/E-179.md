## Experiment: E-179 — The command-not-found signature is a shell diagnostic, not a phrase in the output

- **Date:** 2026-11-17
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-177/E-178 bounded the glob signature to what a shell prints, but left its sibling command_not_found as a bare phrase match anywhere in the output. In this checkout that phrase is ordinary content: hooks/engine/modules/audit.py carries it in the failure table and in the hint text, so a successful `grep -rn "command not found" hooks/engine/modules/audit.py` is classified as a failed command today (reproduced 2026-11-17), and the shipped trail already holds sed/cat reads of module source recorded as command_not_found. A bare phrase cannot separate a shell diagnostic from a file that merely mentions one, so the class is only correct if it matches the shape the SHELL prints: a shell name at line start, then the phrase on the same line.
- **Hypothesis:** H-179: "command_signature_accuracy == 1.0"
- **Measurement Metrics:** command_signature_accuracy == 1.0
- **Experiment Design:** Inputs: the shipped engine module hooks/engine/modules/audit.py and the pre-E-177 tree at git 205fa6d. Procedure: scripts/bench/bench_audit_signature_shapes.py runs twelve probes in their own process against the tree under test: five shell diagnostics that must classify (assistant bash line form flat and inside a nested envelope, the /bin/bash line 7 form recorded in the trail, the zsh trailing form, the sh N: form, and a diagnostic preceded by ordinary output), five payloads that mention the phrase without being a shell diagnostic and must stay silent (the module source itself, a grep result line, a docstring line, the harness returnCodeInterpretation label, and fish vocabulary), one class-routing probe (a glob abort stays glob_nomatch), and one end-to-end audit() probe (a prose payload that mentions the phrase writes no row and warns nothing). Control: --broken runs the same probes against 205fa6d, whose bare phrase regex fires on every prose payload. Reproducibility: stdlib only, offline, deterministic (git archive prefix tree; no network, no clock dependence).
