## Experiment: E-006 — Close the top-level payload seam: repo_root must not crash on a mistyped cwd

- **Date:** 08.10.2026
- **Status:** completed
- **Theory:** Self-hosting discipline (P4 + ASLA #60) plus the engine's published
  contract that every hook mode must END with a decision (E-002 closed the
  non-object-stdin class, E-003 the anti-shape tool_input class). Behavior
  probing of the remaining wire surface found the third seam of the same class:
  the top-level payload key `cwd`, read by `utils.repo_root()` and handed
  straight to `_msys_to_native()`. A well-formed object carrying a mistyped cwd
  (`123`, `4.5`, `true`, `["x"]`, `{"a": 1}`) raises `AttributeError: 'int'
  object has no attribute 'replace'` inside the handler — probe proves guard,
  quality, audit, stop and session_start all exit 1 with empty stdout and NO
  decision (neither the deny JSON nor exit 2), a no-decision turn the runner may
  read as an allow; hook-entry.sh only `_fail`s when python/engine is missing,
  so a Python-level exception never reaches that path. This is exactly E-002's
  Known Gap: the input-boundary guard classifies non-object stdin but does not
  validate the shape of keys inside a well-formed object. The root signal is a
  priority chain (env > payload cwd > process cwd); a non-string cwd is not a
  root signal at all, so it must be skipped — never honored (a coerced "123"
  would fabricate a root under the process cwd: a silently wrong tree) and
  never crashed on.
- **Hypothesis:** H-006: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit. Procedure —
  run `python scripts/bench/bench_consistency.py`, which evaluates independent
  doc/code-consistency claims and prints `consistency_accuracy=(x/y)`; two new
  checks pin the E-006 claim (repo_root falls back instead of raising on every
  non-string cwd shape while a string cwd stays honored; the seam is covered by
  unit and end-to-end tests), and the suite's pytest falsifier covers the new
  regression tests. Control — the bench's own "pytest suite green (falsifier)"
  check pins that the code under test still passes the full suite.
  Reproducibility — stdlib only, no network, deterministic (a fixed tree yields
  a fixed x/y); the measurement reports the tree as it is, independent of this
  record (E-001).
