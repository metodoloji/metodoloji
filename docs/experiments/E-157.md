## Experiment: E-157 — The tag bench measures the published run, not HEAD

- **Date:** 2026-11-14
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-155's instrument encoded a stricter rule than the rule's owner. bench_consistency._check_release_numbering_rule states the contract verbatim: 'The chain may stop short of HEAD (tags are pushed separately); it may not skip a number in between.' E-155's probes 1 and 5 required every position through HEAD, which was true at its measurement commit (b36ede7, position 191, v0.2.91) and false at the next commit (position 192, untagged until the release workflow runs). The full suite caught it within minutes of the next commit, and the failure was not a repo defect: an instrument that goes red on every commit after approval measures the absence of a CI run, not the chain's integrity. E-157 aligns the probe with the owner's contract — the published run must be contiguous and correct from position 0, and a shorter tail is legal — and removes the live-state assertion from the unit suite, where it can only assert a fact that changes with every commit.
- **Hypothesis:** H-157: "release_tag_accuracy == 1.0"
- **Measurement Metrics:** release_tag_accuracy == 1.0
- **Experiment Design:** Inputs: the local repository at this commit plus the pre-repair tag map captured by E-155 (docs/experiments/E-155/raw/control-tags.json), which keeps the control arm offline and unchanged. Procedure: scripts/bench/bench_release_tags.py now runs four probes over the PUBLISHED run: (1) positions 0..newest-tagged each carry their rule tag on the rule's commit, with no gap inside the run and no requirement that the run reach HEAD; (2) every release tag resolves inside the enumerated history; (3) every release tag name is producible by versioning.auto_position; (4) the newest release's tree holds its own number in all five version-owned files. Control: --broken evaluates the same four probes against the E-155 captured map, whose published run (0..47) has a hole and seven misplaced tags, and must score below the threshold. Reproducibility: stdlib + git, offline, deterministic.
