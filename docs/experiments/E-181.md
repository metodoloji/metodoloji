## Experiment: E-181 — A collapsed path is the program's diagnostic, not any line naming one

- **Date:** 2026-11-17
- **Status:** completed
- **Record Kind:** contract
- **Theory:** E-177 through E-180 made the failure table program-diagnostic shaped; backslash_path kept the bare pattern cannot access [a-z]:[^/\\\\] with no line anchor and no program prefix. It never fired on a real failure in the 800 recorded terminal calls (0 hits with command_failed), but it fires on ordinary reads: reading hooks/engine/tests/test_audit.py lines 751-765, or scripts/bench/bench_audit_failure_signals.py lines 106-115 (both reproduced 2026-11-17), yields backslash_path and tells the agent to rewrite a path with forward slashes while it only printed a file. The class is only correct when a filesystem tool prints the diagnostic itself (ls: cannot access C:Usersx), so the pattern needs the program prefix at line start and the real collapsed-drive shape.

Control: --broken runs the same probes against 205fa6d, whose unanchored phrase fires on every prose payload.
