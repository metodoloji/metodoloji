## Experiment: E-196 — A bounded list names the remainder it hid, on every surface

- **Date:** 22.11.2026
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Found live on this tree, 2026-11-22, by posting four anchorless hand-offs to each of two methodology stages. The stop report said '8 unclaimed signal(s)' and then named five, with no marker: 'BUT: E-001 (UNKNOWN, for bmad-sprint-planning), E-002 (...), E-003 (...), E-004 (...), E-001 (UNKNOWN, for bmad-create-story) may no longer apply'. Three signals were invisible — and the outer bound of five was reached only because a per-skill 'signals[:3]' had already dropped two more, so the bound hid items it had room to show. The session-start inject had the mirror defect in the same sentence family: 'NOTE: 4 of them carry no code-state anchor (UNKNOWN: E-001, E-002, E-003)' — a stated count contradicting the list beside it. E-195 counted the story denials' issues; the counted join was written for that one call site, so these two joins kept slicing. A bounded list is a claim about the whole list, so the counting must live in one helper the callers cannot slice around.
- **Hypothesis:** H-196: "list_remainder_accuracy == 1.0"
- **Measurement Metrics:** list_remainder_accuracy == 1.0
- **Experiment Design:** Inputs: a real blackboard in a scratch project root with four anchorless hand-offs posted (through the shipped CLI, in its own process) to each of bmad-sprint-planning and bmad-create-story — eight flagged signals, two channels; plus direct calls to the join helper with 1, 5, 6, 8 and 11 items. Procedure: scripts/bench/bench_list_remainder.py runs ten probes in separate processes — the remainder is counted, the visible bound stays at five, singular and plural are distinguished, a list exactly at the limit and a one-item list are unmarked, a custom separator survives into the marker, E-195's debanded issue strings are byte-identical after the delegation, the live stop report names five of eight and counts three, the live inject names three unknown keys and counts the fourth, and no raw slice of a claim list remains in stop.py or audit.py (comment lines excluded). Control: --broken runs the same probes against the pre-change tree at git 0953f6b (which predates E-192 through E-195; none of those changes is in it) — no counted helper and both raw slices, so its two live probes print the observed defect verbatim. Reproducibility: stdlib plus git only, offline, deterministic; the seeded board is rebuilt per probe.
