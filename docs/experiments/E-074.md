## Experiment: E-074 — Three inventories stop describing a tree that no longer exists

- **Date:** 24.10.2026
- **Status:** completed
- **Theory:** E-073 gave rule 7 its first user and found the class it belongs to:
  an artifact that asserts a fact nobody measured. That pass touched the
  prose inventories (counts, suite size, AC categories, `# map:` sections) and
  left three *machine-readable* ones unmeasured, each shipping a claim about
  the tree it travels with:
  1. `bmad/_config/skill-manifest.csv` — the catalogue a BMAD installer reads.
     It listed 125 skills while `skills/` held 129: the four `metodoloji-*`
     entry points (init, verify, audit, gate-setup) were absent, so a host that
     enumerates skills from the manifest could not offer them at all.
  2. `plugin.yaml` — the Hermes manifest that tells the host which tools,
     hooks and commands exist. It declared 5 tools, 6 hooks and 5 commands
     while `__init__.py` registered exactly that set — by hand, on both sides.
     A tool added to `hermes_tools.py` without a manifest row is invisible to
     the host; a hook declared but never registered never fires. Neither
     failure raises anything: both are silent.
  3. `opencode-plugin/tests/` — 22 tests pinning the bridge contract (payload
     mapping, fail-closed decisions, a real `hooks/engine/main.py` subprocess).
     Nothing ran them. `npm test` was a manual line in `docs/OPENCODE.md`, and
     the bench's whole notion of "the suite is green" was `pytest`.
  Three shipped inventories, three claims, zero instruments. That is the same
  defect E-049 recorded for the README counts, one layer down: the documents
  were measured, the artefacts a machine actually consumes were not.
- **Hypothesis:** H-074: "consistency_accuracy >= 0.90"
- **Measurement Metrics:** consistency_accuracy >= 0.90
- **Experiment Design:** Inputs — the plugin repository at this commit.
  Procedure — `python scripts/bench/bench_consistency.py` evaluates the
  doc/code claims the repo makes about itself and prints
  `consistency_accuracy=(x/y)`. Three checks are new: the skill manifest must
  name every directory under `skills/` exactly once, with an existing
  `skills/<id>/SKILL.md` path; `plugin.yaml`'s three `provides_*` blocks must
  equal the tools (`hermes_tools.py` schemas), hooks (`ctx.register_hook`) and
  commands (the `COMMANDS` table `__init__.py` registers in a loop) found in
  source, in both directions; and `node --test` must run and pass in
  `opencode-plugin/`. Control — `python scripts/bench/bench_consistency.py
  --broken`, declared in this record and run by the gate itself: it measured
  0.83 (98/118), which does not clear the claim. The control now seeds a
  dropped manifest row, a hook registered but undeclared, and a bridge payload
  that drops the real `cwd` — one defect per new rule — on a temp copy; the
  live tree is never written, and a mutation whose anchor rots is a hard
  BROKEN-SETUP failure (exit 2), never one silently fewer defect. Falsifiers
  are unit tests: the manifest check is fed synthetic drift (missing row,
  duplicate id, dead path, misfiled path) and must name each; the Hermes check
  is fed an `__init__.py` with the `pre_verify` registration removed and must
  name the hook. Reproducibility — stdlib only, no network, deterministic: a
  fixed tree yields a fixed x/y, independent of this record (E-001). Node is
  not a Python prerequisite, so its check prints `skip` when `node` is absent
  instead of reporting a green it never measured.
- **Sample Size n:** 119 (informational — the gate parses the denominator from
  the bench output; the count grows from 116 with the three new checks)
- **Code Scope:** scripts/bench/bench_consistency.py, scripts/tests/test_selfcheck_scripts.py, bmad/_config/skill-manifest.csv
- **Lineage:** E-073 (the control and the measured-prose doctrine this extends to machine-readable inventories), E-049 (the documented inventory that was measured while the CSV and the Hermes manifest beside it were not), E-050 (the template as the declared owner of a shipped inventory — the shape the manifest check follows: one authoritative set, compared, not restated), E-001 (the self-check false-positive class: an inventory entry pointing nowhere turns a real signal into noise), E-023 (the provenance repair whose corpus had no control: the reason a new claim ships with one)
- **Raw Samples:** none — the bench emits one aggregate over 119 independent doc/code claims plus the failing check's own naming text, not a boolean sample stream
- **Control Command:** python scripts/bench/bench_consistency.py --broken
