## Experiment: E-059 — The evidence plane reads artifacts outside the project root

- **Date:** 17.10.2026
- **Status:** REJECTED
- **Theory:** E-056/E-058 gave the workflow evidence plane a derived, three-valued verdict and a read budget. Both improvements assume the artifact the witness names is part of the run's own project, and nothing enforces that assumption. `evidence.artifact_matches` builds its path with `os.path.join(project_root, raw_path)`, which returns the declared path unchanged when it is absolute and happily normalises `..` segments, then reads whatever it lands on. So a spec (which the model writes) or a stored witness can name `../outside.md`, `docs/../../outside.md` or an absolute path, and every read surface — `status`, `next`, the inventory, and the SessionStart advisory that runs unattended — reads a file the run does not own and turns its token count into a verdict. On the completion side the same predicate is applied without any root check, so such a stage is accepted in the first place. This is the plan's own F-03 shape once more (the surface nobody audits is the one that runs unattended), and the hazard E-058's Known Gaps and QR-019's follow-ups both deferred to its own record. The honest answer for a path that leaves the root is UNKNOWN — "cannot be established" — never `CURRENT` and never `STALE`; and the write that records such a witness should be refused with the cause named.
- **Hypothesis:** H-059: "escape_read_rate <= 0.0"
- **Measurement Metrics:** escape_read_rate <= 0.0 (with `escape_accepted_rate <= 0.0` carried as the completion-gate threshold and false_alarm_rate as the paired control, all parsed from the same bench output)
- **Experiment Design:** Inputs — `scripts/bench/bench_workflow_evidence.py`, extended with a third defect bucket beside the delivery and read-budget ones. Escape bucket: 3 fixtures x 3 read surfaces (9 trials) where the declared artifact genuinely sits OUTSIDE the trial's project root and carries the declared token — the traversal (`../outside.md`), the traversal buried in the middle (`docs/../../outside.md`, which only a normalising check catches), and the absolute path. A trial creates the run, writes the outside file with the token, forces the completion (so the state NAMES the outside artifact and both trees can be probed — the fixed gate refuses to record that witness on its own, and a pre-fix tree, a hand-edited state or an older run leaves exactly this shape behind), then probes the three read surfaces. A surface answers `CURRENT` only by reading the outside file and turning it into a verdict, `STALE` only by reading it and drawing a definite negative, and "no verdict" only by never asking — all three count as escapes, because the honest answer is UNKNOWN. Gate bucket: the same 3 fixtures completed WITHOUT force (3 trials), scored by whether the completion gate accepted them. Controls unchanged: the expectation vector (`trials: stale=12 current=12 unbounded=6 escape=9 gate=3`) fails a fixture that stopped producing trials, `false_alarm_rate` still fails a "mark everything UNKNOWN" non-fix (an in-root, satisfied artifact must stay CURRENT), and `--baseline` reproduces the pre-fix delivery semantics. Procedure — `python scripts/bench/bench_workflow_evidence.py`.
- **Sample Size n:** 9 (escape read trials; the gate bucket's 3 trials are reported as `escape_accepted_rate` and the gate parses the denominators from the bench output)
- **Code Scope:** scripts/bench/bench_workflow_evidence.py, docs/experiments/E-059.md
- **Lineage:** E-058 (the plane this measures; its Known Gaps named this exact hazard — "escape paths outside the project root are neither measured nor confined" — and its read budget makes the bound meaningful only if the path is inside the root to begin with), E-057 (the same bench's second extension; the pattern of adding a defect bucket with its own honest-answer metric — its scope is re-tread here, so its lesson is carried), E-055 (the plane's first measured baseline, measured=1.0 REJECTED on the same bench file — its scope is re-tread here too, and the lesson is the same one this bucket applies: a surface that carries no verdict delivers a false success), E-056 (the single-matcher doctrine this fix must preserve: containment belongs in `artifact_matches`, not in a second opinion elsewhere), E-053 (the bounded-read precedent: a read the plane cannot justify answers UNKNOWN with the reason rather than guessing), E-037 (the class: a plane asserting a fact nobody measured — here every surface asserts freshness about a file it never checked it was allowed to read)
- **Raw Results:** measured=1.0; n=9
- **Uncertainty:** none (lower-bound claim: no small-sample risk)
- **Metric:** consistent (measured escape_read == claimed escape_read)
