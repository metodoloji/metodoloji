## Experiment: E-189 — A decided record's plan is history, not an open operation

- **Date:** 21.11.2026
- **Status:** completed
- **Record Kind:** contract
- **Theory:** Measured live on this tree, 2026-11-21: session_start printed 'Plan progress (GRP): E-005.md 1/5 planned files on disk (4 pending); E-008.md 2/5 planned files on disk (3 pending); E-009.md 2/11 planned files on disk (9 pending) — extend an operation's plan with …' every session, while all three records said Status: completed and their planned paths (bmad/workflow/engine.py, bmad/scripts/blackboard.py …) had moved to hooks/…, so the counts could never reach zero. Enumerating the whole record tree through the shipped open-plans reader: 122 records had pending planned files and EVERY one was decided (120 completed, 2 REJECTED) — zero open operations. Because the open list is name-sorted and capped at three, those decided records occupied every slot a genuinely open plan would need, so the surface that exists to resume a multi-file operation reported only concluded work. This is the E-188 defect one surface over: a derived claim replayed in the present tense without re-deriving whether the thing it describes still exists.
- **Hypothesis:** H-189: "plan_after_decision_accuracy == 1.0"
- **Measurement Metrics:** plan_after_decision_accuracy == 1.0
- **Experiment Design:** Inputs: throwaway project trees holding experiment records written by the bench fixture (Status: completed/approved/superseded/withdrawn/refused/planned/draft/in-progress/absent, an optional Decision line, an optional plan section) plus one on-disk planned file, driven through the shipped SessionStart entry point as a subprocess. Procedure: scripts/bench/bench_plan_after_decision.py runs ten probes — a completed record's plan is silent at the session edge, a still-open record's plan is surfaced with its counts, a REJECTED Decision closes a benign Status, decided records cannot occupy the three open-list slots, the planned-files-on-disk derivation itself is unchanged, the open list and the session clause agree (one formatter), every closed status in the vocabulary is filtered and every open one survives, the Stop report still counts a decided record's plan, and a record without a plan adds nothing. Control: --broken runs the same probes against the pre-change tree at git 69d1309, which surfaces decided records as open plans. Reproducibility: stdlib plus git only, offline, deterministic; each probe gets a fresh tree and its own process.
