## Experiment: E-070 — A completion accepted with `--force` is delivered as a claim about evidence nobody satisfied

- **Date:** 17.10.2026
- **Status:** REJECTED
- **Theory:** `--force` is the kernel's documented escape hatch: it exists for a stage whose evidence genuinely cannot exist in this environment, and the operator is told to name what they forced and why. What the kernel recorded, though, was a witness identical to a satisfied one — `artifact`'s predicate (path, tokens, minimum) or `command`'s argv and rc, dated to the tracked code state — because the witness is derived from the SPEC, not from what actually happened. The plane then did what it does with any witness and re-derived a verdict from it, so a forced completion reads as one of two lies: for `artifact` evidence whose token is missing it reads **STALE**, blaming the workspace for a claim the kernel itself invented (and — worse — that STALE enters `stale_evidence`, so the next `complete` refuses to advance until the operator forces THAT one too: using the escape hatch once locks the run into using it), and for `command` evidence whose argv exits 3 where rc 0 was declared it reads **CURRENT**, vouching that a suite passed against this code state when it never passed at all. Both shapes are one defect: the completion records what the spec asked for rather than what was established, and every read surface repeats it. The honest answer is UNKNOWN naming the force — nothing was established, so nothing can be re-derived — which is the same third value the plane already uses for an unreadable artifact and an undatable command.
- **Hypothesis:** H-070: "forced_claim_rate <= 0.0"
- **Measurement Metrics:** forced_claim_rate <= 0.0 (with `forced_control_rate <= 0.0` carried as the paired control — a GENUINE completion must still answer CURRENT on every surface, and the same unsatisfied evidence must still be REFUSED without `--force` — parsed from the same bench output)
- **Experiment Design:** Inputs — `scripts/bench/bench_workflow_evidence.py`, extended with an eighth bucket. Two fixtures, each completed with `force=True` against evidence that does not hold: an `artifact` stage whose file exists without the declared token (3 read surfaces), and a `command` stage whose argv exits 3 where rc 0 was declared, inside a real git work tree so the code-state dating — which is what makes the false CURRENT reachable — is in force (3 read surfaces). The defect is any verdict other than UNKNOWN: STALE means the plane blames the workspace for its own claim and blocks the next advance on it, CURRENT means it vouches for work that never happened. Control: one fixture (4 trials) — the same missing-token evidence is still refused without `--force`, and after the token is written the completion reads CURRENT on all three surfaces, which fails a "turn every completion into UNKNOWN" non-fix. `--baseline` strips the forced marker from the recorded witness, which is exactly the state the unfixed tree wrote, and then classifies it with real code. Procedure — `python scripts/bench/bench_workflow_evidence.py`.
- **Sample Size n:** 6 (two shapes × three read surfaces; the control's 4 trials are scored separately and the gate parses each denominator from the bench output)
- **Code Scope:** scripts/bench/bench_workflow_evidence.py, docs/experiments/E-070.md
- **Lineage:** E-064 (the command dating whose code-state comparison is what makes a forced command read CURRENT, and the UNKNOWN-with-the-reason vocabulary this bucket reuses), E-056 (the witness — a claim about the workspace — and the STALE verdict that a fabricated claim produces), E-058 (the gate-refuses/view-reports split, and the bounded re-derivation that keeps all three surfaces cheap to probe), E-067 and E-066 (the preceding plane, and the same framing: a surface must not deliver a claim it cannot stand behind), E-062 and E-060 (the containment planes whose scopes this bench's fixtures re-tread), E-069 and E-068 (the immediately preceding pair, and the shared lesson that what a surface STATES is the thing to measure), E-055 and E-057 (the earliest baselines whose scope this draft re-treads, so their lesson is carried: a bucket needs a paired control).
- **Raw Results:** measured=1.0; n=6
- **Uncertainty:** none (lower-bound claim: no small-sample risk)
- **Metric:** consistent (measured forced_claim == claimed forced_claim)
