## Experiment: E-135 — Scoping the witness diff to the claim changes no verdict across the corpus

- **Date:** 2026-11-12
- **Status:** completed
- **Record Kind:** experiment
- **Theory:** E-134 measured that every witness diff was priced by repository size rather than by the claim under test (74 of 74 narrowable records paid at least twice, up to 105x, for paths they could not use) and authorised narrowing the version-control ask to the literal directory prefixes of each Code Scope. The repair is on disk and the end-to-end effect is large: the scan went from 32.7s to 1.6-2.0s on this corpus, which takes a write-shaped command from 4 of 4 probes over the 10s hook budget to none. But a speedup is exactly the kind of change that can be bought with a wrong answer, and this one has an obvious failure mode: if the derived pathspec were too narrow, an in-scope file would look untouched and a record the code moved past would read CURRENT instead of STALE. That is the freshness plane silently approving stale claims, which is worse than the timeout it replaced - a blocked commit is visible, a false CURRENT is not. So this record measures the property the speed must not have broken: for every record in the corpus, the verdict with narrowing and the verdict without it must agree.
- **Hypothesis:** H-135: "freshness_verdict_disagreement_rate <= 0.001"
- **Measurement Metrics:** freshness_verdict_disagreement_rate <= 0.001
- **Experiment Design:** Cells are every record in this corpus that the classifier returns a verdict for - the whole set, not a sample, because a wrong pathspec is exactly the kind of defect that hides in the tail. Each record is classified twice in one process: once as shipped, once with the narrowing disabled so the diff is asked for repo-wide, which is the pre-fix behaviour. The cell passes when the two verdicts agree. The metric is the disagreement rate, so 0.0 means narrowing changed nothing and the claim is <= 0.001. The control replaces the derived pathspec with a deliberately wrong one (always the hooks directory) and runs the identical comparison: a control that cannot produce disagreement would show only that the comparison is blind, so it must score well above the threshold and does - 56 of 130 records flip from STALE to CURRENT, which is precisely the silent-approval failure this record exists to rule out.

What the corpus adds is evidence that no scope in use breaks that argument. A scope whose literal prefix names a path that does not exist, or one written with a Windows separator, is narrowed the same way the glob is normalised; both are covered by the existing matcher parity test rather than by this one.
