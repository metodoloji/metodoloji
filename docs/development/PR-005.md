## Runbook

### Deploy Steps
1. Confirm the local commits are the intended set: `git log --oneline origin/main..HEAD`
2. Run the smoke table above on the tree being pushed.
3. `git push origin main`. CI verifies the pushed tree against the number its position owns and publishes the tag; a stale tree is refused with the number it should have carried.
4. `git fetch --tags` and confirm the tag names the pushed commit.

### Troubleshooting
- **`doctor` still warns "snapshot drifts" on a clean idle board:** the TTL constant and the filter must read the same clock; check that `HANDOFF_SIGNAL_TTL_SECONDS` is the value the fold uses and that the alert's `kind` is `handoff`.
- **A real divergence stops warning:** the filter must touch only `kind == "handoff"` alerts. The census's `snapshot_stale_session_alert_is_drift` and `stale_handoff_plus_snapshot_key_is_drift` cases are the guards; a change that makes either pass is a regression, not a fix.
- **The census measures the pre-fix shape on the landed tree:** `_DRIFT_TTL_NORMALIZED` is the marker the bench reads; if it is missing, the bench deliberately falls back to the candidate contract and the gate's claim is no longer about the shipped code.

### Rollback Steps (Detailed)
`git revert 18ed6a8 cbdd8e4` (newest first), then re-run the two commands in the rollback triggers.
