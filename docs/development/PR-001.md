## Rollback Plan

Revert the push commit. The gate changes are additive: `find_structural_declaration()` is only
reached when no approved record covered the path, and `--control` is optional. A project whose
`docs/development/structural/` directory does not exist behaves exactly as before, which is
pinned by test 6 of `test_structural_scope.py`.

---

## Known Risks

1. **Structural scope is a policy addition.** It creates a way to write code without a
   measurement, by declaration. It is bounded (no `scripts/bench/**`, justification required,
   approval wins, every write warns), but the bound is only as good as the QR that ratifies the
   declaration. A reviewer who rubber-stamps declarations turns the exemption into a backdoor.
2. **Falsifiability enforcement changes gate ergonomics.** Existing records without a
   `Control Command` still verify, but their `Falsifiability: UNVERIFIED` line is now visible in
   every future run.
