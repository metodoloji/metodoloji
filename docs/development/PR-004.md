## Rollback Plan

- **Rollback method:** revert the release commits (`git revert`), newest first, or reset to
  `d635af5` and force-push if the release never left the maintainer's branch.
- **Rollback triggers:**
  - `check-techdebt.sh` reports a structure drift on a clean tree
  - §7 fails on a project whose ledger is legitimately filled (a false placeholder hit)
  - The engine suite or `check-methodology.sh` goes red on a clean tree
- **Rollback duration:** under five minutes
- **Rollback steps:**
  1. Revert `c9d1914` (the counter and the stdin fix) — test-only.
  2. Revert `8db232c`, `0de46bb` (records, ledger, board) — documentation only.

  commits. Reverting `061e99b` alone requires restoring the old template content, because the
  new template no longer matches the old §1 — the revert pair is the commit plus the template.

## Runbook

### Deploy Steps
1. Confirm the local commits are the intended set: `git log --oneline origin/main..HEAD`
2. Run the smoke table above on the tree being pushed.
3. `git push origin main`. CI verifies the pushed tree against the number its position owns
   and publishes the tag; a stale tree is refused with the number it should have carried.
4. `git fetch --tags` and confirm the tag names the pushed commit.

### Troubleshooting
- **§1 reports a structure drift on a filled ledger:** the ledger gained, lost or renamed a
  heading or table column without the template following. Compare the lines the checker prints;
  they are the differing structure entries, not the prose.
- **§7 reports a placeholder in the live ledger:** a slot was copied from the template and
  never filled. The checker prints the matching lines; replacing them with real values is the
  only fix — suppressing the check is not.
- **A new project's ledger starts empty:** that is the intended change. `templates/tech-debt.md`
  is now a template to fill; existing projects keep their own file (the installer never
  overwrites a live ledger).

### Rollback Steps (Detailed)
`git revert c9d1914 8db232c 0de46bb 061e99b` (newest first), restore the pre-release
`templates/tech-debt.md`, then re-run the two commands in the rollback triggers.
