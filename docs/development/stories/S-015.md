## User Story

**As a** maintainer of the metodoloji plugin
**I want** the debt ledger's checker to compare the ledger's shape with the shipped template and to refuse a template placeholder left in the live file
**So that** the one file that records every other debt can testify for its own reporting half, instead of staying green while its metrics read `[X items]`
