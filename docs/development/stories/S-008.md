## User Story

**As a** maintainer of the metodoloji plugin
**I want** the run's declared `artifact` to be delivered only when it resolves inside the run's own project
**So that** the session edge never tells an agent to track its work in a file the run does not own

---

## Acceptance Criteria

> For the story to count as "done", all criteria must be met

- [AC-001] **Given** a spec whose declared `artifact` resolves outside the project root (`../…`, a traversal in the middle, an absolute path) **When** `status` or the session advisory is read **Then** the path is not delivered as the run's tracking location — `artifact` is None with a note naming the declaration and the root, and the advisory names it as outside
  - Experiment: E-067
  - Type: agent-verifiable
  - Measured: true
  - Verify: python scripts/bench/bench_workflow_evidence.py
- [AC-002] **Given** a spec that declares an out-of-root `artifact` **When** `create` is called **Then** the run is refused, naming the cause, and no spec copy is written
  - Experiment: E-067
  - Type: agent-verifiable
  - Measured: true
  - Verify: python scripts/bench/bench_workflow_evidence.py
- [AC-003] **Given** a spec whose declared `artifact` is inside the project **When** the surfaces are read **Then** it is delivered verbatim (no over-refusal), and an undeclared one reports None rather than a guess

### Decisions
