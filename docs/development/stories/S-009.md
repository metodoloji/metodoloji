## User Story

**As a** maintainer of the metodoloji plugin
**I want** `workflow.py status` (and `next`/`resume`/`history`) without `--slug` to answer from the stored names
**So that** asking which run I meant does not derive an evidence verdict for every run in the project

### Decisions

- 2026-10-17: "one row per state file" is preserved — `store.list_slugs` lists the same files the inventory enumerated, so corrupt runs still count as names (pinned by a test).
- 2026-10-17: the 0.0 control is the load-bearing half: a resolver that answered "no single run" would be free and useless.
