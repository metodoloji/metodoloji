## User Story

**As a** maintainer of the metodoloji plugin
**I want** a stage completed with `--force` to record that it was forced
**So that** the plane neither blames the workspace for a claim it invented nor vouches for a command that never passed

### Decisions

- 2026-10-17: one existing test was repaired, not weakened — it used `--force` only as a way to plant a witness, and with the marker that witness never reaches the read budget it was written to exercise; it now records a genuine witness and grows the artifact afterwards.
