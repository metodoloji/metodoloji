## User Story

**As a** maintainer of the metodoloji plugin
**I want** a run's evidence to be read only from inside the project the run lives in
**So that** a spec or a stored witness can never make the plane read (and report on) a file the run does not own

### Decisions
- 2026-10-17: containment lives in `evidence.artifact_matches` — the single matcher the completion check and every re-derivation already share (E-056's doctrine) — rather than in spec validation or in each caller. A witness stored by an older tree, or edited by hand, is therefore read through the same containment as a freshly declared path; a second check elsewhere would be a second opinion.
- 2026-10-17: the two sides keep their E-058 asymmetry. A gate refuses (the completion path maps the shared `None` to "not satisfied", naming the cause); a view reports (the read surfaces answer UNKNOWN). Neither invents a STALE.
