## User Story

**As a** maintainer of the metodoloji plugin
**I want** the board's doctor to apply the same 24-hour handoff TTL to the snapshot and to the replayed log before it compares them
**So that** an idle board can no longer read as corrupted state, and the audit stops prescribing a snapshot rebuild for a board that is only old
