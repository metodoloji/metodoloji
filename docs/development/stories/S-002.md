## User Story

**As a** maintainer of the metodoloji plugin
**I want** every recorded decision dated to the code state it was written against
**So that** a signal whose claim the code has moved past is reported as "this may no longer apply" instead of being obeyed as live work

---

- [AC-001] **Given** a hand-off signal citing a decision whose scope the code has moved past **When** it is delivered on the peek or the session-start inject **Then** it carries the STALE verdict and its age, and is never framed as live work
  - Experiment: E-053
  - Type: agent-verifiable
  - Measured: true
  - Verify: python scripts/bench/bench_freshness.py

  - Experiment: E-053
  - Type: agent-verifiable
  - Measured: true
  - Verify: python scripts/bench/bench_freshness.py
- [AC-003] **Given** a claim whose code state cannot be established (no witness, no git, unreadable scope) **When** it is classified **Then** it reads UNKNOWN, never a silent CURRENT

  - Verify: python -m pytest hooks/engine/tests/test_freshness.py -q
