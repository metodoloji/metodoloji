## User Story

**As a** maintainer of the metodoloji plugin
**I want** the evidence verdict on every surface an operator reads, computed on a bounded read
**So that** a run whose foundation moved is never listed as healthy, and opening a session never scans an unbounded artifact set

> For the story to count as "done", all criteria must be met

- [AC-001] **Given** a completed stage whose artifact no longer satisfies its predicate **When** the run inventory (`list`) is read **Then** that run carries the STALE verdict for the stage and names it in `stale_evidence`
  - Experiment: E-058

  - Measured: true

- [AC-002] **Given** an artifact past the read budget (wider than the per-candidate byte bound, or buried under more glob matches than the scan bound) **When** the verdict is re-derived **Then** it reads UNKNOWN with the reason, never CURRENT from an unaffordable read and never a false STALE
  - Experiment: E-058
  - Type: agent-verifiable
  - Measured: true
  - Verify: python scripts/bench/bench_workflow_evidence.py
- [AC-003] **Given** a match found INSIDE the read budget **When** the stage is classified **Then** it answers CURRENT exactly as before (the budget degrades information, never correctness)

  - Type: agent-verifiable

- [AC-004] **Given** a stage being completed **When** its evidence is accepted **Then** the completion read is not bounded, so a large deliverable can still be accepted (and only its later re-derivation answers UNKNOWN)
