## Runbook

### Deploy Steps
1. Confirm the five local commits are the intended set: `git log --oneline origin/main..HEAD`
2. Run the smoke table above on the tree being pushed.
3. `git push origin main`. CI verifies the pushed tree against the number its position owns
   and publishes the tag; a stale tree is refused with the number it should have carried.
4. `git fetch --tags` and confirm the tag names the pushed commit.

### Troubleshooting
- **The notice never appears:** the plane never crossed its cap, or the crossing is read
  after the fold trimmed it (the first implementation did exactly this and scored 0.73).
  Run the census; the `overflow_*` samples tell the two apart.
- **A duplicate re-subscribe prints the notice:** the dedupe check was bypassed before the
  growth test. Run `pytest -k subscription_cap`.
- **`check-techdebt.sh` reports a template/live mismatch:** the ledger was edited without
  copying it over `templates/tech-debt.md`. §1 demands byte identity until TD-017 is repaid.

### Rollback Steps (Detailed)
`git revert 5affa6e 8c7dab8 7bfd06a` (newest first), resolve the ledger conflict by taking
the pre-release copy, then re-run the two commands in the rollback triggers.
