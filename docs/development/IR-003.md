# Implementation Readiness: IR-003 — Derive a workflow stage's evidence verdict (E-056)

- **Date:** 2026-10-17
- **Status:** READY
- **Research inputs:** E-056 (APPROVED + VERIFIED — the evidence plane and its measurement); carries E-055, the measured baseline failure (stale_evidence_rate = 1.0 on the unfixed kernel), and the doctrine of E-053/E-054 (witness + derived verdict, three-valued)
- **Design documents:**
  - PRD: none
  - UX Spec: none
  - Architecture Plan: none
- **Success criteria:**
  - A completed workflow stage whose artifact no longer satisfies its declared predicate is delivered as STALE on both read surfaces, never as satisfied work — Metric: stale_evidence_rate; Source: `python scripts/bench/bench_workflow_evidence.py` (two surfaces: `status` and `next`); Target: 0.0, with false_alarm_rate 0.0 as the paired control
  - The plane is predicate-sensitive, not digest-sensitive: an edit that keeps the declared tokens stays CURRENT — Metric: false_alarm_rate; Source: the same bench (8 current trials, two of them artifact edits that keep the token); Target: 0.0
  - The verdict is three-valued and `UNKNOWN` never degrades to `CURRENT` — Verify: `python -m pytest bmad/tests/test_workflow.py -q` (legacy completion without a witness reads UNKNOWN and stays advanceable; an unreadable artifact reads UNKNOWN, not STALE)
  - `complete` refuses to advance onto a foundation whose evidence no longer holds, and the existing `--force` escape hatch still overrides — Verify: `python -m pytest bmad/tests/test_workflow.py -k stale_foundation`
  - The session edge (the surface where stale context gets obeyed) names the moved foundation — Verify: `python -m pytest bmad/tests/test_workflow.py -k advisory`
  - Non-functional: no new dependency, offline and deterministic, one derivation feeding every surface — Verify: `python -m pytest -q` plus the bench, both stdlib-only
- **Instrumentation gaps:**
  - "the earlier stage was the *right* work" → not measurable: the plane measures whether the evidence the completion was recorded against still holds, not whether the stage's output was correct. `command` evidence ("this argv exited 0") is history rather than a workspace claim and is not dated by this record.
- **Technical dependencies:**
  - APIs: none
  - Libraries: none (stdlib: glob, os, pathlib, time)
  - Infrastructure: none new; the kernel already owns its storage under `.metodoloji/workflow/`
  - External services: none
- **Risk assessment:**
  - Risk 1: a digest-sensitive design would call a stage stale every time a later stage appends to the tracked artifact → Mitigation: the recorded predicate is re-applied (tokens + minimum), and the bench's `rewritten-with-token` / `glob-other-match` fixtures fail a digest-only non-fix
  - Risk 2: the refusal blocks legitimate runs → Mitigation: only STALE refuses (UNKNOWN never does), it is scoped to the stages the spec declares as `requires`, and `--force` remains the kernel's documented escape hatch
  - Risk 3: a second matcher drifting from the kernel's own → Mitigation: `_check_evidence` and the read surfaces call ONE function (`evidence.artifact_matches`), so a completion cannot be recorded under a predicate the plane scores differently
- **Gaps:**
  - none — the TOCTOU window between check and write is a documented limit of the kernel class (E-036 Known Gaps); this plane measures it, it does not claim to remove it
- **Decision:** READY — the research input is approved and verified (E-056, APPROVED + VERIFIED); the closure is mechanical and offline
