## Findings

- **Finding 1 (design, accepted in review):** the dating decides between CURRENT and UNKNOWN only. A look cannot falsify "this argv exited 0", so a command verdict is never STALE and never blocks an advance — the opposite of the artifact plane, where a re-read CAN falsify a token claim. Recording that asymmetry in the rule list (rule 9) matters more than the code: it is the reason `complete`'s refusal list did not change.
- **Finding 2 (cost discipline, resolved in review):** the probe is a subprocess on the session edge, which E-058's doctrine would reject if it ran per run. It is therefore lazy and shared per read pass (`CodeStateProbe`); the inventory classifies every run and pays exactly one call, and a project whose completions are all artifact evidence pays none. `list_runs` passes the probe explicitly rather than letting each `verify` open its own.
- **Finding 3 (existing test changed, deliberate):** `test_witness_is_recorded_only_for_artifact_evidence` asserted that a `command` stage records NO witness — it encoded rule 5's old doctrine, which E-063 measured as the defect. It is rewritten as `test_witness_records_artifact_predicates_and_dated_commands`, which is a STRONGER assertion (it pins argv, rc and a non-null code state, and that an artifact witness carries no code state). This is the requested behaviour change, not an assertion weakened to pass.
- **Finding 4 (measurement honesty):** the control is not a "must be 0 on both trees" control, and the record says so: on the unfixed plane the same-state fixture ALSO failed, by silence (there was no verdict to be CURRENT). The pair is what makes the metric meaningful — silence fails both directions, an "always UNKNOWN" non-fix fails the control, and only dating passes both.
- **Finding 5 (known gap, recorded):** the fingerprint covers TRACKED files only, so an untracked file a command read can change without moving the verdict; every reason string says "tracked", and E-064's Known Gaps records that no fixture pins an untracked-file change. The probe's cost is bounded by a declared timeout (5 s) and is not timed by the bench. A non-git project can never answer CURRENT for a command completion — honest, and the price of having no oracle.
- **Finding 6 (pre-existing, not caused by this change):** `scripts/check-plugin.sh` still reports the same 11 `UNVERIFIABLE` records (E-024 … E-034) it reported before this work — the documented machine-local key contract. Audit §3b is green: every edited file sits inside an approved Code Scope; the E-056/E-058/E-060/E-062 records report `[STALE]` as report-only under `[hooks] freshness = warn`.
