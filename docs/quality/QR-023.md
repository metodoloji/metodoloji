## Findings

- **Finding 1 (why this survived two planes, recorded because it is the lesson):** the field is never OPENED — it is repeated. E-060 governs reads, E-062 governs resolution, and both asked "is this file opened?", so a pointer that is only handed to the agent passed under them. The defect class is "what does this surface hand over", and the plan had only ever asked the read question. That is why the gap sat in two Known Gaps lists as if it were documentation.
- **Finding 2 (design, accepted in review):** the fix does not annotate the pointer, it withholds it. `status.artifact` stays a string-or-null and never carries a non-owned path; the declaration survives in the additive `artifact_note`. Annotating (returning the path with "this is outside" beside it) would leave the consumed field usable by an agent that ignores the annotation, which is the exact failure mode being closed.
- **Finding 3 (asymmetry, deliberate):** `create` refuses and the read surfaces report. A legacy run whose saved spec carries an outside pointer therefore still runs — its surfaces name the declaration and the remedy — while no NEW run can be planted with one. That mirrors E-058's gate/view split and keeps a spec edit (not a kernel decision) as the way to fix an old run.
- **Finding 4 (measurement honesty):** this bucket measures the fixed tree through real code (the run is created clean and its SAVED copy is then given the pointer), so the green is not a model. `--baseline` models the pre-fix delivery for this bucket — recorded as such in the bench docstring and E-067's Experiment Design, because no unfixed path remains to call. The baseline numbers (1.0 / 1.0) were measured live on the unfixed tree before the fix.
- **Finding 5 (pre-existing, not caused by this change):** `scripts/check-plugin.sh` still reports the same 11 `UNVERIFIABLE` records (E-024 … E-034) it reported before this work — the documented machine-local key contract. Audit §3b is green: every edited file sits inside an approved Code Scope; the earlier hardening records report `[STALE]` as report-only under `[hooks] freshness = warn`, and their own buckets were re-measured green in this iteration's run.
