## Findings

- **Finding 1 (why this was invisible, recorded because it is the lesson):** every witness the plane derived was TRUE until an operator used `--force`, because the derivation ran only after a satisfied check. The bug was in the record's PROVENANCE: it said "the predicate held" while what had happened was "the spec declares this predicate". A derived record must name what it was derived from — observation or override — and that is now the marker.
- **Finding 2 (design, accepted in review):** the fix adds no verdict. UNKNOWN already means "nothing can be established" (an unreadable artifact, an undatable command), which is precisely what a forced completion is; the change is naming it so that value is reachable, and refusing to enter it into `stale_evidence` — which is what made one forced stage lock the run into forcing every later one.
- **Finding 3 (existing test repaired, deliberately):** `test_a_candidate_past_the_byte_budget_never_produces_a_false_stale` used `--force` only as a vehicle to plant a witness, because no other path writes one the gate would refuse. With the marker that witness short-circuits to UNKNOWN before the read budget is consulted, so the test stopped exercising the budget. It now completes on a genuine witness and grows the artifact afterwards — the realistic sequence, and a strictly stronger fixture: the assertion on the budget wording is unchanged.
- **Finding 4 (boundaries kept, deliberate):** the gate is untouched. `--force` still overrides both the evidence check and the STALE-foundation refusal (that is the flag's documented meaning), and the stages it bypassed stay named in `stale_evidence`. Only what the completion LEAVES BEHIND changed, which is why no refusal text, exit code or CLI surface moved.
- **Finding 5 (pre-existing, not caused by this change):** `scripts/check-plugin.sh` still reports the same 11 `UNVERIFIABLE` records (E-024 … E-034) it reported before this work — the documented machine-local key contract. Audit §3b is green: every edited file sits inside an approved Code Scope; the earlier hardening records report `[STALE]` as report-only under `[hooks] freshness = warn`, and their own buckets were re-measured green in this iteration's run.
